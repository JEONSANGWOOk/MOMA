# extctrl_linux reference configuration

These configuration files are preserved from `moma/extctrl_linux/viewer` as the source for the Windows MoMa viewer preset. The Windows app reads its own saved `viewer3d` settings; these files document the original model choices and FR5/AMR parameters.

The current preset applies the SDC-400EU-light GLB and the extctrl FR5 mount pose. Robot motion remains governed by MOMA-main's existing FR5 simulator and hardware adapter.
