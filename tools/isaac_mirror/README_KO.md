# 파이썬 3D → Isaac Sim 실시간 미러

## 구성과 범위

실제 MoMa/FR5 → 기존 파이썬 프로그램 → 표시용 geometry/transform 파일 → 조회 전용 HTTP → Isaac Sim USD Mesh.
Isaac Sim에서는 로봇으로 명령을 보내지 않습니다. ROS 2, 별도 URDF 재작성, 설비 GLB 수동 재배치 없이 시작할 수 있습니다.
로봇 베이스, FR5 링크, 엔드이펙터, 설비, 양쪽 문, 휴대폰 패널의 현재 표시 배치를 전달합니다.
부품별 원본/파이썬 표시 재질 색상을 전달하며 조명·질감·렌더러가 달라 픽셀 단위 외형은 일치하지 않을 수 있습니다.
이 미러는 동적 물리/충돌 시뮬레이션이나 Articulation 제어 모델이 아닙니다. 문 각도는 파이썬의 표시용 추정값입니다.
지도 점군·벽·가상벽·경로·노드 및 실시간 라이다 점군도 전달합니다. 화면 문자 라벨·카메라 영상은 별도입니다.

## 1. Isaac Sim 설치 (현재 설치 전)

1. NVIDIA 공식 설치 페이지에서 Windows용 최신 정식 **Workstation standalone** 패키지와 해당 버전 Compatibility Checker를 받습니다.
2. Compatibility Checker로 GPU·VRAM·드라이버·운영체제를 확인하세요. 이 PC의 조회 결과는 RTX 5080, VRAM 약16GB, RAM 약64GB입니다.
3. 공식 설치 안내에 따라 압축 해제 및 post_install.bat를 실행하고 Isaac Sim을 시작합니다. 옛 Omniverse Launcher 경로를 사용하지 마세요.
4. 처음 실행은 셰이더 준비와 에셋 다운로드로 오래 걸릴 수 있습니다.
5. 파이썬 UI와 Isaac Sim이 GPU를 공유하므로 모델 로드 후 프레임 속도/메모리를 확인하세요.

공식 문서:
- 설치: https://docs.isaacsim.omniverse.nvidia.com/latest/installation/install_workstation.html
- 요구사항: https://docs.isaacsim.omniverse.nvidia.com/latest/installation/requirements.html
- 다운로드: https://docs.isaacsim.omniverse.nvidia.com/latest/installation/download.html

설치 파일의 자동 다운로드/설치는 수행하지 않았습니다. Isaac Sim 런타임 코드의 실제 실행 검증은 설치 후 필요합니다.

## 2. 파이썬 UI 실행 (PowerShell)

```powershell
cd -LiteralPath 'D:\MOMA-main_2026-11-03[Samsung_confidential]\MOMA-main'
.\run_isaac_mirror_windows.bat
```

이 실행기는 기존 run_windows.bat의 가상환경 선택을 유지하고, MOMA_ISAAC_MIRROR=1만 추가합니다.
먼저 SIM에서 **3D 화면을 열어 둡니다.** 현재 3D를 그리는 데이터가 최대 20Hz로 게시됩니다.
다른 탭이나 2D로 전환하면 게시가 멈출 수 있습니다. Isaac Sim은 2초간 새 프레임이 없으면 마지막 자세에서 멈춥니다.
실기 표시 시에는 기존 방식으로 실기 조회 연결, 현재 지도, 관절 수신을 확인합니다. Isaac 연결 자체는 제어권을 요구하지 않습니다.

파일은 기본적으로 사용자 홈 `.seer_amr_console/isaac_mirror`에 저장됩니다. 다른 폴더는 MOMA_ISAAC_DIR 환경변수로 지정합니다.
모델 geometry는 한 번, 이후 프레임은 부품 변환값 위주로 게시하며, 기록 작업은 별도 스레드에서 수행합니다.

## 3. 조회 전용 브리지 실행 (별도 PowerShell)

```powershell
cd -LiteralPath 'D:\MOMA-main_2026-11-03[Samsung_confidential]\MOMA-main'
python tools/isaac_mirror/serve.py
```

기본 주소는 `http://127.0.0.1:8770`입니다. `/manifest`와 `/frame` GET만 제공합니다.
브라우저에서 `/frame`이 열리고 sequence가 증가하는지 확인하세요. 503이면 파이썬의 3D 화면과 미러 실행 여부를 확인합니다.
geometry가 큰 경우 `/manifest`의 첫 응답은 큽니다. 파일에는 현장 CAD가 포함될 수 있으므로 공개 서버에 노출하지 마세요.

## 4. Isaac Sim에서 수신 실행

Isaac Sim에서 **File → New**로 빈 Stage를 만들고 **Window → Script Editor**를 엽니다.
아래를 Script Editor에서 실행합니다. 일반 PowerShell의 `python`으로 실행하는 스크립트가 아닙니다.

```python
import omni.usd
from pxr import UsdGeom, UsdLux
stage = omni.usd.get_context().get_stage()
UsdGeom.SetStageMetersPerUnit(stage, 1.0)
UsdGeom.SetStageUpAxis(stage, UsdGeom.Tokens.z)
light = UsdLux.DomeLight.Define(stage, '/World/MOMA_MirrorLight')
light.CreateIntensityAttr(500)

from pathlib import Path
MOMA_MIRROR_URL = 'http://127.0.0.1:8770'
script = Path(r'D:\MOMA-main_2026-11-03[Samsung_confidential]\MOMA-main\tools\isaac_mirror\isaac_live_view.py')
exec(compile(script.read_text(encoding='utf-8'), str(script), 'exec'), globals())
```

Stage 트리에서 `/World/MOMA_Mirror`를 선택하고 **F**로 화면을 맞춥니다.
처음에는 메시/재질을 순서대로 만들기 때문에 시간이 걸릴 수 있습니다. 이후 로봇과 문/패널이 파이썬 표시를 따라갑니다.
Play를 누를 필요가 없습니다. 물리 시뮬레이션이 로봇 자세를 결정하지 않습니다.
Stage를 다른 파일로 바꾸면 수신 스크립트는 새 Stage에 미러를 다시 생성합니다. 새 Stage도 Z-up, 1m 단위여야 합니다.
같은 수신 스크립트를 다시 실행하면 이전 수신 인스턴스를 중지합니다.
중지는 Script Editor에서 `_MOMA_MIRROR.close()`를 실행합니다.
이 스크립트는 `/World/MOMA_Mirror` 하위만 교체하며 다른 사용자 모델은 지우지 않습니다.

## 5. 다른 PC에서 Isaac Sim을 실행할 때

파이썬 PC의 동일 네트워크에서만 사용하세요. 브리지 실행 예:

```powershell
python tools/isaac_mirror/serve.py --host 0.0.0.0 --port 8770
```

필요하면 관리자 PowerShell에서 PC IP 대역에 한정해 허용합니다:

```powershell
New-NetFirewallRule -DisplayName 'MOMA Isaac read-only mirror' -Direction Inbound -Protocol TCP -LocalPort 8770 -RemoteAddress 192.168.30.0/24 -Action Allow -Profile Any
```

Isaac 수신 스크립트의 MOMA_MIRROR_URL에는 **파이썬 실행 PC**의 IP를 입력합니다. 로봇 제어 PC .13이 아닙니다.
Isaac PC에는 `isaac_live_view.py`만 복사해도 됩니다. 모델은 네트워크로 전달됩니다.
이 간단한 브리지는 인증/TLS를 제공하지 않으므로 인터넷 포트포워딩을 하지 마세요.

## 좌표·수신 상태·검증

- 기준: 미터, Z-up. 파이썬 column-vector 변환 행렬은 USD row-vector 행렬로 전치합니다.
- 동일 FK/문 힌지 변환을 전달하므로 엔드이펙터 및 설비 위치를 다시 추정하지 않습니다.
- 수신 스레드는 데이터만 받고 USD 수정은 Kit 메인 업데이트 콜백에서 수행합니다.
- 프레임 누락은 최신 프레임으로 대체합니다. 재연결 시 이동 명령이나 지난 프레임을 재생하지 않습니다.
- `/World/MOMA_Mirror`의 customData.connection이 LIVE / STALE - frozen을 표시합니다.
- REAL 상태 데이터가 2초 이상 오래되거나 연결이 끊기면 자세를 고정합니다. 관절 정보의 출처는 metadata.arm_source에 표시합니다.
- 이번 로컬 검증: 메시 분할·재질·FK 행렬·원자적 파일·읽기 전용 HTTP·일반 Python 문법 검증. Isaac Sim USD API 실행/실제 GPU 화면 검증은 아직 미완료입니다.

설치 후 먼저 SIM에서 AMR 이동, 관절 자세, 좌우 문, 패널 XY, 설비 XY/yaw가 양쪽에서 일치하는지 확인하세요.
실기 검증은 기존 프로그램의 조회 연결에서 위치/관절을 받아 비교하며, 미러 확인을 위해 실제 이동 명령을 자동 실행하지 않습니다.

## UI 버튼으로 간편 연결 (추천)

기존 run_windows.bat로 파이썬 프로그램을 실행해도 됩니다. 상단 **Isaac Sim 연결**을 누르세요.
1. 최초 1회 **찾아보기**에서 Isaac Sim 설치 폴더의 `isaac-sim.bat`를 선택합니다.
2. **연결 / Isaac Sim 실행**을 누르면 3D 화면 전환, 미러 송출, 로컬 HTTP 브리지, Isaac Sim 시작 및 수신 스크립트 실행을 자동으로 처리합니다.
3. 수신기에서 모델 생성·정상 프레임 적용이 확인되면 창에 **Isaac Sim 연결됨**으로 표시됩니다.
4. 다음 실행부터 설치 경로를 기억합니다. 별도 PowerShell이나 Script Editor 작업이 필요하지 않습니다.
5. 이미 수동 실행한 Isaac Sim을 사용하려면 **브리지만 실행** 후 위의 Script Editor 코드를 최초 1회 실행하세요. 기존 프로세스에는 임의로 코드를 주입하지 않습니다.
6. **송출 중지**는 브리지/게시만 중단합니다. Isaac Sim은 저장하지 않은 장면을 보호하기 위해 자동 종료하지 않습니다.

기본 브리지는 127.0.0.1:8770이며 외부 연결을 열지 않습니다. 다른 프로그램이 포트를 점유하면 오류를 표시합니다.
설정: 사용자 홈 `.seer_amr_console/isaac_connection.json` / Isaac 시작 로그: `.seer_amr_console/isaac_mirror/isaac_startup.log`.
설치가 안 된 상태에서도 브리지만 켤 수 있습니다. Isaac Sim 설치 후 실행 버튼을 다시 누르세요.
자동 시작은 Kit의 공식 --exec 옵션을 사용합니다: https://docs.omniverse.nvidia.com/kit/docs/kit-manual/110.1.5/guide/python_scripting.html
실제 Isaac Sim은 아직 설치 전이므로 자동 시작부터 USD 화면까지의 실기 실행 확인은 설치 후 필요합니다.

## 상단 버튼 한 번으로 자동 연결

상단 **Isaac Sim 연결**을 누르면 저장된 경로와 알려진 설치 폴더를 자동 검색하고 바로 브리지·송출·Isaac Sim 실행을 시작합니다.
현재 설치 경로 `D:\isaac-sim-standalone-6.2.0-windows-x86_64\isaac-sim.bat`도 자동 감지합니다.
찾아보기와 두 번째 실행 버튼은 정상 경로가 감지된 경우 누를 필요가 없습니다. 경로를 찾지 못했을 때만 선택창이 열립니다.
이미 시작 중이거나 정상 수신 중인 경우 기존 연결을 유지합니다.

## 지도·실시간 LiDAR 표시

Map/Cloud는 저장 지도 점군(최대 4만 점), Map/Walls·VirtualWalls는 벽, Map/Routes는 경로, Map/Nodes는 노드 위치입니다.
노드 이름은 Stage의 Map/Node_* 표시 이름 및 station 속성에서 확인합니다.
LiDAR는 파이썬에서 지도 좌표로 변환한 최신 점군(최대 4천 점)을 센서 높이 0.1965m에 표시합니다.
별도 센서 시뮬레이션이 아닌 실제 수신 점군 시각화이며, 파이썬 화면의 LiDAR 표시 스위치와 독립적으로 송출됩니다.
2초 이상 오래된 점군과 연결 단절 시에는 라이다를 숨깁니다. 로봇·설비는 마지막 자세에 고정됩니다.
최초 모델·지도 생성 후 전체 장면으로 카메라를 자동 맞춤합니다. 필요하면 Stage의 /World/MOMA_Mirror 선택 후 F로 다시 맞추세요.
코드 갱신 후 파이썬과 Isaac Sim을 재시작해야 새 수신 코드가 로드됩니다. 브리지는 UI 버튼으로 다시 시작합니다.

## 로봇 원본 전체 메시

MoMa 차체와 엔드이펙터는 미리보기용 면 축소 모델이 아닌 원본 GLB를 송출 스레드에서 별도로 읽습니다.
MoMa 1,497,564면, 엔드이펙터 104,514면을 원본 전체 면 수와 대조합니다. FR5는 기존 full_visuals 원본 메시를 유지합니다.
USD Mesh에는 면 삭제 없이 공유 정점과 원본 삼각형 인덱스를 전달합니다. 최초 manifest는 gzip 압축하며 이후에는 변환값만 갱신합니다.
첫 로딩은 더 오래 걸릴 수 있으며 메모리 사용량이 증가합니다. 파이썬과 Isaac Sim을 모두 다시 실행해야 적용됩니다.

## 실험용 문 물리모드 (실물 저항값 미측정)

기존 실시간 미러는 문 각도까지 파이썬 값을 표시합니다. **문 물리 시뮬레이션**을 선택해 새로 실행하면
로봇은 수신한 자세로 움직이는 kinematic body이고, 양쪽 문은 질량을 가진 dynamic body + revolute hinge입니다.
문 각도는 물리 계산에 맡기며 파이썬 문 각도로 계속 덮어쓰지 않습니다. 초기 각도만 파이썬 표시를 사용합니다.

### 실행

1. 현재 Isaac Sim을 종료합니다. 파이썬도 재시작해 새 모델 메타데이터를 송출합니다.
2. 파이썬 상단 **Isaac Sim 연결**에서 **문 물리 시뮬레이션**을 체크하고 **연결 / Isaac Sim 실행**을 누릅니다.
   자동 실행으로 이미 미러모드가 열렸으면 Isaac Sim을 닫은 뒤 다시 연결하세요. 모드 변경은 다음 실행에 적용됩니다.
3. 모델 로드·physics collider cooking이 끝난 뒤 Isaac Sim에서 **Play**를 누릅니다.
4. 후크가 손잡이에 실제로 걸려서 당겨지거나 롤러가 문 표면을 밀면 충돌 제약으로 문이 움직이도록 구성됩니다.
   접촉 모델은 자동으로 궤적을 맞추거나 후크를 손잡이에 고정하는 가상 흡착 기능이 아닙니다.
5. 연결/상태 수신이 끊기면 물리 재생을 Pause합니다. 다시 연결한 후 사용자가 Play로 재개합니다.
   설비 배치를 변경하면 기존 물리 힌지와 일치하지 않으므로 Pause하고 장면을 재생성해야 합니다.

### 초기 추정값: 양쪽 문에 동일 적용

| 항목 | 초기값 |
|---|---:|
| 문 한쪽 질량 | 3kg |
| 접촉 정지/운동 마찰계수 | 0.5 / 0.3 |
| 반발계수 | 0 |
| 힌지 마찰계수 | 0.05 |
| 회전 감쇠 | 0.2 /s |
| 열림 제한 | 0~120°, 좌우 힌지 부호 반영 |
| 접촉 여유 | 2mm |
| 물리 시간 단계 | 120Hz |

설정 파일: `config/isaac_door_physics.json`.
이 값들은 측정치가 아니고 최적값도 아닙니다. 양쪽 실물 문 무게가 같다는 보장도 없습니다.
관성은 형상과 질량에서 엔진이 추정합니다. 문 잠금/래치·실제 힘센서·마찰 측정값은 포함하지 않았습니다.
후크 collider는 원본 concave triangle mesh를 유지하고, 문 collider는 convex decomposition을 사용합니다.
정밀한 걸림은 collider cooking 결과와 실물 CAD의 틈새에 따라 달라질 수 있습니다.
구조 검증: Isaac 6.2 설치 USD/PhysxSchema에서 양쪽 강체·질량·힌지·마찰·좌우 제한·후크 collider 설정 검증 완료.
**실제 PhysX Play에서 후크 당김 → 롤러 밀기 궤적이 성공하는지와 실물 동작 일치 여부는 아직 검증하지 않았습니다.**
