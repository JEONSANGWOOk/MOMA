# 사용자 모드의 실시간 지도 경로 설정

작업 운영 화면에서 지도 노드를 클릭하면 클릭한 순서대로 방문 목록에 추가됩니다.
일반 미션에서 지도 노드를 클릭하면 `지도 경로 이동` 미션으로 전환됩니다.
이 미션은 목록의 마지막 노드에서 끝나며, 출발점으로 자동 복귀하지 않습니다.
기존 `현재 노드 왕복 테스트`를 선택한 상태에서는 방문 목록 끝에 출발 노드 복귀가 추가됩니다.

- 삭제할 방문 항목을 목록에서 선택하고 `선택 삭제` 또는 Delete 키를 누르세요.
- 지도에서 Shift를 누른 채 노드를 클릭하면 그 노드의 마지막 방문 항목을 삭제합니다.
- `전체 삭제`로 방문 목록을 비울 수 있습니다.
- `지도 경로 설정` 버튼이나 미션 타입의 `지도 경로 이동`으로 경로 편집을 열 수 있습니다.

추가·삭제 결과는 지도에 즉시 표시됩니다. 같은 노드를 여러 번 방문할 수 있습니다.
경로를 수정하면 이전 실행 확인이 취소됩니다. `경로 / 작업 미리보기`에서 순서와 연결 경로를
확인한 뒤 `시작`을 누르세요. 빈 경로나 연결되지 않은 경로는 실행할 수 없습니다.
실행 중인 미션의 방문 목록은 수정할 수 없으며, 먼저 해당 미션을 종료해야 합니다.

검증: 전체 단위 테스트 438개와 `tools/operator_map_route_smoke.py`의 실제 Tk 지도 클릭,
경로 표시, Shift/Delete/전체 삭제, 실행 확인 무효화, 왕복 미션 유지 및 실행 중 편집 차단.
검증에는 임시 설정과 시뮬레이터를 사용했습니다.
