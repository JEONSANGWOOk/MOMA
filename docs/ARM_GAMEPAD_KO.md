# 동일 DualSense로 AMR / 로봇팔 조종

Windows USB/Bluetooth CFI-ZCT1G를 기존 `컨트롤러 검색 / 설정`에서 선택합니다. `수동 조작`과 `조이스틱 사용`을 켜고 `조종 대상`을 AMR 또는 로봇팔로 선택합니다. 로봇팔 개발 워크스페이스에도 같은 선택/연결/조작 상태를 표시합니다.

- AMR: 기존 전후진/회전 조작 유지.
- 로봇팔: 왼쪽 스틱 두 축을 `J1/J2`, `J3/J4`, `J5/J6`, `TCP X/Y`, `TCP Z/RZ`, `TCP RX/RY` 중 선택합니다. 좌우 축은 첫 번째, 전후 축은 두 번째 항목입니다. 실제 축 방향은 입력 설정의 반전값을 따릅니다.
- 스틱 중앙에서 L1을 놓았다가 누르면 조종합니다. L1 해제, 창 포커스 상실, 입력 지연/장치 해제, 모드/축 변경 시 조종을 중단합니다. 모드/축 변경 뒤에는 중앙에서 다시 시작합니다. ○ 버튼은 조이스틱을 비활성화하고 정지합니다.
- SIM: 관절 12°/s, TCP 위치 30mm/s, TCP 회전 10°/s 이내. URDF 관절 범위, 이동 구간 충돌 검사, 기존 팔 물리 장면 적용. 재생/미션/AMR 주행 중에는 수동 팔 조종하지 않습니다. 공유 관절 상태를 변경하므로 메인 모바일 매니퓰레이터 3D도 동기화됩니다.

## FR5 실기 JOG

상단 REAL 모드에서 기존 FR5 연결 설정(IP 기본 192.168.58.2), 제어기 버전/SDK 호환 확인, 실기 동작 허용, FR5 연결 시험을 완료해야 합니다. AMR 제어/연결 상태가 유효하고 정지해 있어야 합니다. 조이스틱 설정의 `이번 실행에서 FR5 실기 조이스틱 JOG 허용`을 별도로 켭니다. 이 허용은 시작 시 항상 꺼져 있습니다.

FAIRINO 공식 `StartJOG(ref, nb, dir, max_dis, vel, acc)`와 `ImmStopJOG()`를 사용합니다. ref=0 관절, ref=2 로봇 base TCP 좌표. 두 스틱 축 중 입력이 큰 한 축을 선택합니다. 실기는 동시 두 축 움직임이 아니라 짧은 단일 축 펄스를 반복합니다. 펄스 최대 0.2° 또는 0.3mm, 최대 5% 속도, 0.08초 후 즉시 JOG 정지를 요청합니다. 전송 직전에 입력 유효기간 및 제어기 오류/비상정지/안전정지/정지 상태를 재확인합니다. 입력 해제 시 별도 정지 채널로 ImmStopJOG를 요청합니다. 소프트웨어/네트워크 정지 확인은 컨트롤러 응답에 의존하며 최대 거리 제한도 함께 적용합니다. 활성화/모드변경/원점복귀 API를 자동 전송하지 않습니다.

실기 조종 중 팔 표시가 SIM 개발이었다면 실기 수신 자세로 전환합니다. 실제 수신 자세는 SIM 관절값을 덮어쓰지 않습니다. SIM 충돌 장면이 실기 안전 기능을 대신하지 않습니다. 실기는 공식 제어기 안전 기능을 사용하며 실제 하드웨어 검증은 아직 수행하지 않았습니다.

공식 API 근거: [FAIRINO Python Movement](https://fairino-doc-en.readthedocs.io/3.8.0/SDKManual/PythonRobotMovement.html).
