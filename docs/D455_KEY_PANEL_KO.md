# 전기 판넬 열쇠 삽입·회전 시뮬레이션

`D455_Key_Panel.cmd`를 실행하면 내장 모의 카메라로 정렬 → 접근 → 22 mm 삽입 → 열쇠 끝을 중심으로 90° 회전하는 동작을 시작합니다. 로봇 연결 없이 실행합니다. 기존 펜 마킹 프로그램은 별도로 유지됩니다.

## 화면과 조작

- **열쇠 삽입 → 90° 잠금해제**: 두 마커의 중간점과 판 자세로 손잡이의 슬롯 좌표를 매 프레임 계산합니다. 열쇠의 위치·방향을 보정하고 삽입, 회전합니다.
- **열쇠 후퇴**: 현재 열쇠 방향을 유지하며 빠져나와 100 mm 거리에서 추종합니다. 이 일반 잠금 모델은 0°/90°에서 열쇠를 뺄 수 있습니다.
- **정지 / 초기화**: 초기화는 동작이 정지되고 열쇠가 완전히 빠져 있는 상태에서만 가능합니다.
- **모의 판넬 이동·회전**: 접근, 삽입, 회전 중 움직이는 기준판을 추종하는 시험입니다. 모의 입력만 바꾸며 D455 데이터 파일을 수정하지 않습니다.
- **마커 소실 시험 / 일치하는 열쇠**: 영상 소실 시 정지하고, 다른 열쇠는 잠금해제 회전 단계로 진행하지 않습니다. 영상이 돌아와도 자동 재개하지 않습니다.
- **손잡이·열쇠 확대**: 실제 열쇠 끝 좌표, 슬롯 단면, 삽입 깊이와 회전 각도를 확인합니다. 마우스 왼쪽 회전, 오른쪽 이동, 휠 확대도 가능합니다.

`D455 실시간`을 선택하면 기존 D455 인식기의 두 마커 기준판 데이터를 사용합니다. D455 인식 창을 실행하고 등록한 마커 두 개를 같은 판에 고정해 보여주세요. 세 프레임 확인 후 가상 좌표 기준을 설정합니다. 카메라를 손으로 움직이는 시험에서는 상대적인 판넬 이동으로 해석합니다. 열쇠구멍의 좌우/상하 위치는 마커 중간점 기준 mm입니다. 기본값은 좌우 0, 상하 +100 mm입니다.

## 형상과 판정

일반 철제 전기 판넬(600×800×150 mm), 문, 힌지, 검정 손잡이, 은색 실린더, 실제 빈 슬롯과 슬롯 뒤 벽, 황동 열쇠, 손가락 그리퍼를 모델링합니다. 열쇠는 초기부터 파지된 상태이며 별도 집기 동작은 없습니다. SIM 추정값은 키 외경 8 mm·내경 6 mm, 키홀 외경 9 mm·중앙 핀 직경 4.8 mm입니다. 열쇠 끝 TCP는 기존 그리퍼 장착 기준 +165 mm를 유지합니다. [사진 모델 설정](D455_PANEL_HANDLE_KO.md)을 참고하세요.

회전 진입은 계산된 **실제 FK 열쇠 끝**의 횡방향 오차 ≤0.25 mm, 축 오차 ≤0.5°, 삽입 깊이 ≥21.7 mm와 일치하는 열쇠가 필요합니다. 잠금해제는 실제 회전 각도가 90°에 도달한 뒤에만 표시합니다. 회전 시 슬롯 실린더는 맞물린 열쇠와 함께 회전하고, 열쇠 끝의 위치는 계속 유지합니다. 로봇·그리퍼·열쇠와 판넬의 충돌 검사를 적용합니다. 영상 지연/소실, 기준 변경, 급변, 역기구학 오류와 충돌은 정지 조건입니다.

`artifacts/electrical_panel/panel_reference.png`는 AI로 생성한 일반 형상 참고 이미지입니다. 사진과 3D 모델은 특정 실물 판넬의 정밀 복제물이 아닙니다. GUI 슬롯/열쇠 모델이 충돌과 판정의 기준입니다. 표시된 마커 판은 위치를 보여주는 도식이며 인식 가능한 출력용 ArUco 이미지가 아닙니다.

현재 접촉은 기하학적 간섭 모델이고 핀 텀블러, 삽입력, 마찰 토크, 문 열기 동작은 구현 범위에 포함되지 않습니다. 실제 장비 제어에는 실물 슬롯/키 치수, 마커-구멍 관계, 카메라-로봇 보정, 열쇠 TCP와 힘/토크 제어가 필요합니다. 이 프로그램은 로봇 SDK나 실제 장치에 명령을 보내지 않습니다.

## 판단 로그

`.delivery/d455_key_panel/decisions.jsonl` 및 `decisions.txt`에 각 단계, 영상 시각/기준 버전, 목표 좌표, 실제 FK 좌표, 횡방향 오차, 깊이, 축 각도, 명령/실제 회전, 열쇠 일치 여부, 잠금 상태와 동작 결론을 남깁니다. 충돌 중간 자세도 별도로 기록합니다. 센서 힘이나 실제 토크 측정값으로 해석하면 안 됩니다.

개발 검증: `py -3 -m unittest tests.test_key_panel` 및 `py -3 tools/d455_key_panel.py --smoke`. GUI 검증 결과와 캡처는 `.delivery/d455_key_panel_verification.json`, `.delivery/d455_key_panel.png`입니다.
