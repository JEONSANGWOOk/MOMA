# 3D 지도와 로봇 모델

기본 모델은 **SEER AMB-CSW04-CE + FAIRINO FR5**입니다. AMR은 흰색 차체, 청색 표시등, 검은 범퍼·바퀴, LiDAR와 비상정지 버튼을 표현하며, 팔은 흰색 링크와 주황색 관절의 6축 형태를 표현합니다. 두 URDF는 이 앱에서 작성한 경량 도형 모델이며 제조사 정밀 CAD 메시가 아닙니다. AMR 상부의 팔 장착대는 시뮬레이터용 가상 부품입니다. 기본 SEER 모델은 SIM 충돌 검사에 차체 크기의 외접 원을 적용합니다. 외부 모델은 주행 모델의 길이/폭/반경도 맞춰 설정해야 하며, 실제 장비 설정은 변경하지 않습니다. [SIM 충돌·우회 옵션](SIM_OBSTACLES_KO.md)을 참고하세요.

참고 자료: [SEER AMB-CSW04-CE 제품 치수](https://cn-cdn.seer-group.com/amr/liftingrobot/AMB-CSW04-CE), [FAIRINO FR5 제품 정보](https://fairino.com/FR/4.html), [FAIRINO 공식 FR5 V6 관절 정의](https://github.com/FAIR-INNOVATION/frcobot_ros2/blob/main/fairino_description/urdf/fairino5_v6.urdf). 기본 AMR 차체 치수는 958.2 × 631.4 × 182 mm를 기준으로 합니다. FR5 관절 간 거리와 범위는 공개 자료를 참고하되 외형 세부, 색상 위치, 작업 자세는 단순화했습니다. 기본 SIM 팔의 동작은 합성 자세이며 실제 FR5 동작 정확도를 보증하는 모델은 아닙니다.

다른 모델을 불러온 상태라면 설정 창의 `기본 FR5 복원` / `기본 SEER 복원`으로 되돌릴 수 있습니다. 정밀 모델이 필요하면 제조사 URDF와 링크별 메시를 가져오세요.

`지도 / 제어` 상단에서 **2D / 3D**를 선택합니다. 노드·경로 편집 화면은 기존 2D 편집기로 유지됩니다.

- 시점: 사선, 위, 정면, 측면, 뒤, 로봇 추적, 뒤따라 보기. 원근/직교 투영을 선택할 수 있습니다. `뒤따라 보기`는 로봇 뒤에서 위치와 방향을 함께 따라갑니다. 기존 `로봇 추적`은 위치만 따라갑니다. 뒤따라 보기 중 왼쪽 드래그로 회전하거나 오른쪽 드래그로 이동하면 자동 추적이 해제되며 시점 메뉴를 다시 선택하면 재개됩니다.
- 운행 지도 위의 레이어 스위치는 2D 편집 지도와 공유하며 3D에도 적용됩니다. LiDAR 스위치로 실제/SIM 레이저 점 표시를 켜고, 상태줄에서 수신 점 수·수신 지연·장애물 상태를 확인하세요. 3D에서는 기존 XY 레이저 데이터를 참고 높이 196.5 mm의 평면에 표시합니다. 실제 XYZ 점군을 측정하는 3D 센서 표시는 아닙니다.
- 왼쪽 드래그: 회전. 오른쪽 드래그: 화면 이동. 휠: 확대/축소. `맞춤`: 전체 지도.
- 클릭: 노드 선택과 우측 목적지/옵션 갱신. 더블클릭: 기존 확인창을 거쳐 선택 노드로 이동. 우측 `선택 노드로 이동` 버튼도 동일하게 사용합니다. 드래그한 경우에는 노드를 선택하지 않습니다.
- 재배치 모드에서는 클릭으로 지도 위치를 지정하고, 수동 모드의 왼쪽 드래그는 방향을 지정합니다. 주황색 후보 위치/방향을 표시하고 기존 확인 절차를 사용합니다. 모터, 정지/재개, 미션, 수동 조작은 기존 우측 제어를 사용합니다.
- AMR의 현재 X/Y/방향이 3D 모델에 계속 반영됩니다. 팔은 AMR 좌표계에 장착되므로 AMR과 함께 이동합니다.
- 지도, 점군, 경로, 좌표축, AMR, 로봇팔, CAD 표시를 각각 켜고 끌 수 있습니다.

## 모델 가져오기

`3D 모델 / 관절`에서 가져오기 대상을 AMR, 로봇팔, 장면 CAD 중 선택합니다.

URDF는 box/cylinder/sphere와 STL/OBJ mesh visual, origin XYZ/RPY, fixed/revolute/continuous/prismatic 관절, 관절 범위와 mimic을 지원합니다. Xacro는 미리 URDF로 생성해야 합니다. `package://` mesh 참조가 있으면 패키지들이 들어 있는 상위 폴더를 지정합니다. 누락되거나 지원되지 않는 visual은 경고를 표시하고 제외합니다. DAE, 텍스처, collision/inertial 시각화는 지원하지 않습니다.

STL은 ASCII/바이너리, OBJ는 다각형 면과 음수 정점 번호를 지원합니다. 메시 단위를 m/mm로 지정하세요. URDF는 m/rad 기준입니다. STEP/IGES는 CAD 도구에서 STL/OBJ로 내보내서 불러옵니다. 메시만 가져오면 관절이 없는 정적 모델입니다. 관절 운동을 보려면 링크별 메시를 가진 URDF를 사용하세요.

팔 장착 XYZ/RPY는 AMR 좌표계 기준, 장면 CAD 배치 XYZ/RPY는 지도 좌표계 기준입니다. 모델 경로, 장착/배치 위치, 벽 높이, 표시 옵션과 선택한 보기 방식은 저장됩니다. 참조 파일을 이동하면 다시 지정해야 합니다.

## 동작 표현과 범위

기본 예제 6축 팔은 SIM의 작업/안전 자세 진행률에 맞춰 합성 관절값으로 움직입니다. 설정 창의 `SIM 팔 동작 보기` 또는 기존 팔 테스트를 사용할 수 있습니다. 외부 URDF는 관절 슬라이더로 수동 확인하고, 실제 수신 데이터의 `joint_positions` 사전 또는 `joint_states`의 name/position 배열이 URDF 관절 이름과 일치하면 해당 값을 표시합니다. 슬라이더를 움직이면 미션 연동이 해제되며, 연동 옵션으로 다시 켤 수 있습니다. 슬라이더는 실제 로봇에 명령을 보내지 않습니다.

이 기능은 앱 내부의 3D 시각화입니다. ROS 노드, TF, JointState 구독, MoveIt/IK 및 물리 충돌 시뮬레이션은 연결하지 않았습니다. 실제 팔 제어기 연동에는 별도의 관절 상태 수신 연결이 필요합니다. 2D 벽은 설정한 높이로 표현하고 기존 점군은 바닥에 표시하므로 측정된 3D 지형을 의미하지 않습니다.

추가 그래픽 라이브러리 없이 소프트웨어로 그립니다. 메시 파일은 64 MB 이하, URDF는 8 MB 이하이며 큰 메시의 면 수를 줄여 표시합니다. 복잡한 CAD에는 면 정렬·가림 표현의 한계가 있으므로 가벼운 시각화용 메시를 권장합니다.
