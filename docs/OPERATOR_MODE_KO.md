# 사용자 / 개발자 모드 · v1.35

현재 Windows 프로그램에서 같은 실행 엔진을 사용합니다. 상단 사용자/개발자 선택으로 전환하며 마지막 선택을 저장합니다. 기존 개발 작업의 연속성을 위해 처음 실행은 개발자입니다. 작업 중에는 모드 전환하지 않습니다. 모드 선택은 화면/기능 구분이며 로그인·비밀번호 기반 보안 인증은 아닙니다.

## 사용자

작업 운영과 음성/LLM 메뉴만 보입니다. 연결 정보는 유지하며 IP/API/모델 설정은 개발자가 먼저 준비합니다. SIM/REAL 상태는 상단 배지에 표시됩니다.

1. 미션 타입과 목적지를 선택합니다. 필요한 미션에만 픽업/복귀 위치가 표시됩니다.
2. 실행 횟수 1~100을 지정합니다. 1회는 템플릿 전체 순서이며 개수와 동일하려면 개발자가 한 회당 하나를 처리하는 작업으로 등록해야 합니다.
3. 경로/작업 미리보기에서 순서와 지도 연결을 확인합니다. 60초 유효, 설정 변경 또는 위치가 25cm 이상 달라지면 다시 확인합니다.
4. 시작하고 현재 단계/반복/위치/장애물 대응을 확인합니다. 일시정지/재개/취소/정지를 사용할 수 있습니다.
5. 수행 보고서와 작업 이력에서 반복별 이벤트를 확인합니다. 목적지 패스/후속 작업 생략이 있는 완료는 부분 완료로 표시합니다.

이동만, 순환 운반은 기본 제공됩니다. 자재 공급·완제품 회수는 초기 미허용 상태입니다. 로봇팔 좌표를 추측하지 않으며 등록된 작업과 목적지를 연결한 뒤 배포해야 합니다.

## 개발자

기존 지도/경로, Taskchain, 모델, I/O, 팔 개발, 조이스틱 메뉴를 유지합니다. 운영 미션 구성에서 이동/팔 작업/대기 블록을 추가하고 드래그 또는 위/아래 버튼으로 순서를 바꿉니다. 블록 값과 사용 목적지를 지정하고 사용자 실행 허용을 켜서 저장/배포합니다. 팔 작업이 포함되면 목적지 하나를 명시해야 합니다. 다른 설비는 별도 이름의 템플릿으로 복사하여 해당 위치에 맞게 티칭합니다. 복잡한 I/O·조건·팔 동작은 기존 프로그램으로 개발한 뒤 팔 작업 블록에서 선택합니다.

REAL용 작업은 공식 SDK 설정, 확인된 제어기 버전, 연결·상태·제어권과 팔 안전 자세 조건을 유지합니다. 실제 하드웨어 검증은 아직 수행하지 않았습니다.

## LLM

사용자 모드에서 개발 메뉴 명령, 지도 좌표 편집, 임의 팔 작업을 거부합니다. 개발자 때 만든 GUI 명령을 보관해도 사용자로 전환하면 실행할 수 없습니다. LLM으로 모드를 전환하지 않습니다. 직접 위치 이동과 정지·미션 상태 명령은 기존 동작을 유지합니다.

예: `LM1에서 LM3로 순환 운반 두 번`. 운영 미션 명령 미리보기를 실행하면 작업 화면에 입력하고 경로를 확인하며, 주행은 작업 운영의 시작 버튼으로 실행합니다. `자재 공급`은 설정되지 않은 경우 시작할 수 없습니다. 역할 전환 시 이전 LLM 명령을 폐기합니다.

현재 노드 왕복 테스트: 노드 0.25m 이내에서 정지하고 다른 목적지를 선택한 후 미리보기 → 시작. 방문 후 미리보기 당시 출발 노드로 복귀하며 실행 횟수만큼 반복합니다. 중간 경유 노드는 정지 없이 통과합니다.
