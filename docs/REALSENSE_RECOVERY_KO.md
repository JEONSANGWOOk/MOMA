# RealSense 카메라 복구 버튼

Python 프로그램을 재시작하면 상단 `RealSense 실시간 보기` 옆에 `RealSense 카메라 복구` 버튼이 표시됩니다. 버튼을 누르면 설정된 Runtime 서버의 `_camera_preview_only` 함수만 한 번 호출합니다. 연결 확인 응답만으로 성공으로 표시하지 않고 영상 주소에서 JPEG 3프레임을 디코딩한 뒤 해상도와 성공 결과를 표시합니다.

복구 중에는 버튼을 비활성화하고 네트워크 처리는 별도 스레드에서 실행합니다. 실패·시간 초과 시 자동으로 재전송하지 않습니다. Python에서 추적 중인 Runtime 시나리오가 실행 중이면 완료 후 사용하도록 안내합니다. 기존 카메라 영상 창은 자체 재연결로 영상을 다시 수신합니다.

제어 PC에는 카메라만 재초기화하는 `_camera_preview_only` 함수가 설치돼 있어야 합니다. 현재 제어 PC에는 원본 `scenario.py`를 백업하고 해당 함수를 추가한 상태입니다. 이 버튼은 함수 설치·시나리오 소스 다시 읽기·Viewer 재시작을 자동 수행하지 않습니다. 로봇 연결, AMR/팔 이동, IO 출력, 위치 재배치 명령도 호출하지 않습니다. USB 연결 끊김이나 다른 카메라 프로그램 점유가 원인이면 먼저 그 상태를 해결해야 합니다.
