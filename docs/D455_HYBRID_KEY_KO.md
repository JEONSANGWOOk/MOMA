# 마커 + 손잡이 외형·구멍 중심 결합

통합 화면의 **D455 추종 방식 (SIM)**에서 **마커만** 또는 **마커 + 손잡이·구멍 인식**을 선택합니다. 기본은 **마커만**입니다. 마커만 선택하면 이미지 등록 없이 등록된 두 마커의 중간점 기준으로 **구멍 좌우 mm / 구멍 상하 mm** 값을 사용합니다. 실제 구멍이 중간점에 있으면 두 값을 0으로 입력합니다. 두 마커의 검출·최신 영상·자세 확인은 계속 필요합니다. 이 옵션은 SIM에 적용되며 REAL/SIM+REAL은 기존 실측 보정 설정을 사용합니다.

시작 대기 중 방식을 바꾸면 시작 대기를 취소합니다. 실행 중에는 정지하고 열쇠를 후퇴한 뒤 방식을 바꿉니다.

MOMA의 **비전 · 판넬 작업**에서 사용할 수 있습니다. ArUco 두 마커로 판넬 위치와 표면 방향을 얻고, 사용자가 지정한 실제 열쇠구멍 주변 외형을 등록해 구멍 중심의 좌우·상하 오차를 보정합니다. 등록한 영상 패치를 마커 자세에 맞게 펼쳐 비교하는 방식이며, 대규모 데이터로 학습한 신경망 모델이 아닙니다.

1. 두 마커와 실제 손잡이·열쇠구멍을 카메라에 함께 보이게 합니다. 마커는 같은 판넬에 고정해야 합니다.
2. 카메라 탭의 **손잡이·구멍 등록**을 누릅니다. 정지된 원본 영상에서 실제 열쇠구멍 중심을 클릭합니다.
3. 마커 평면에서 구멍 입구까지 높이를 입력하고 저장합니다. 기본 32 mm는 기존 SIM 추정값입니다. 실제 높이와 다르면 입력을 수정해야 하며, 이 입력만으로 실측 보정이 완료되지는 않습니다.
4. **마커 + 손잡이·구멍 인식**을 선택하고 **D455 실시간 추종 시작 (SIM)**을 누릅니다. 두 마커와 구멍의 검출이 준비될 때까지 시작을 대기합니다.
5. 구멍의 초록 십자, 외형 일치 점수, 기준판 기준 XYZ를 확인합니다. 정렬 → 삽입 → 30° 회전 → 자동 후퇴를 수행합니다. 구멍이 가려지거나 외형 일치가 낮아지면 전진·회전은 보류하며, 이전 구멍 위치와 현재 마커 자세로 보정을 계속합니다. 영상 소실·충돌 등 기존 정지 조건은 유지합니다.

외형 일치 점수는 삽입 성공 확률이 아닙니다. 최소 점수 0.78, 후보 중복 검사, 새 영상 3프레임 확인, 등록 중심 대비 10 mm 보정 범위를 적용합니다. 동일 프레임 반복은 검출 확인 횟수에 포함하지 않습니다. 구멍 중심이 갑자기 변하거나 작업 중 등록 revision이 바뀌면 삽입을 보류하고 재시작이 필요합니다. 손잡이 주변 모양·조명이 크게 바뀌면 다시 등록합니다. 열쇠에 의한 구멍 가림도 검출 실패가 될 수 있습니다.

등록 영상과 설정은 `.delivery/d455_handle_target.json`에 로컬로 저장합니다. **등록 삭제**는 이 등록을 삭제합니다. 실제 손잡이가 없으면 검출을 만들어내지 않습니다. 내장 모의 카메라의 기존 동작은 별도 SIM 시험입니다.

REAL/SIM+REAL 경로에도 결합 좌표 계산을 연결했습니다. 실기 보정의 `hybrid_target_verified=true`, `hybrid_target_revision`이 실제 등록 revision과 일치하고 등록의 `dimension_source=measured`여야 사용합니다. 마커·카메라·열쇠 TCP·구멍 높이의 실측 확인 이후에만 이 설정을 사용할 수 있습니다. 추정 등록은 실기 결합에 사용할 수 없습니다. XY 보정은 실측 슬롯 위치 대비 10 mm, 높이는 0.2 mm 이내로 제한하고, 영상·마커 급변·힘/토크 보호는 유지합니다. 기본 설정은 실기 결합을 활성화하지 않습니다.

이 개발의 영상 시험은 생성 영상으로 위치·기울기 변화와 구멍 가림을 재현한 검출 테스트입니다. 실제 손잡이에서의 검출 정확도·실물 열쇠 삽입 성공률은 현장에서 검증해야 합니다. 열쇠 끝의 영상 검출과 접촉 힘 기반 미세 탐색은 이 구현에 포함되지 않았습니다.

검증: `.venv-vision\Scripts\python.exe -m unittest tests.test_handle_vision`, `py -3 -m unittest tests.test_hybrid_key_target tests.test_key_panel_real`.
