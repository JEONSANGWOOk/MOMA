# 제공된 제품 사진으로 구멍 위치 추정·삽입 SIM

카카오톡으로 전달한 KAHL-1057-B(R) 제품 사진의 본문 제품 영역을 기준으로 등록했습니다. 상단 원형 실린더 중심을 사진 좌표로 지정하고 사진 특징점과 호모그래피를 이용해 카메라 영상에서 그 위치를 찾습니다. 동일한 사진을 화면에 표시하는 시험용 등록이며, 실물 손잡이를 인식하도록 학습한 신경망 모델은 아닙니다.

1. **비전 · 판넬 작업 → 카메라 · ArUco → 학습한 제품 사진 화면에 표시**를 누릅니다. F11은 전체 화면, Esc는 닫기입니다. 다른 노트북·휴대폰에 `.delivery/kahl_screen_reference.png`를 띄워도 됩니다.
2. D455로 표시된 사진을 봅니다. 사진 전체가 카메라에 보이고, 너무 작거나 화면 반사가 심하지 않도록 조절합니다.
3. 실행 모드는 **SIM**으로 두고 **사진 추종 시작 (SIM)**을 누릅니다. 사진 검출을 시작하고 신뢰 조건을 충족한 새 영상 3프레임과 가상 기준 좌표를 기다립니다.
4. 카메라 영상의 사진 외곽선과 **PHOTO HOLE / SIM** 십자를 확인합니다. 제품 사진 일치 특징점 수와 구멍 픽셀 좌표가 표시됩니다. 가상 로봇팔은 사진에서 추정한 위치·자세를 추종하며 정렬 → 삽입 → 30° 회전 → 자동 후퇴합니다.

사진 추종에서는 ArUco를 검출한 것으로 간주하지 않습니다. 실제 마커 수는 카메라에서 검출한 수 그대로 표시합니다. 추종 입력은 `vision_source=photo_screen_sim`, `geometry_source=photo_screen_estimate`, `markers_used=0`으로 구분합니다. 화면 속 사진은 물리적인 구멍이 없으므로 삽입은 3D 시뮬레이터에서만 수행합니다. 사진의 2.8 px/mm 크기는 기존 제품 형상의 추정 크기를 위한 SIM 가정이며, 출력 화면 크기·실제 카메라 거리의 실측 값이 아닙니다. 실제 깊이·로봇 베이스 좌표를 보장하지 않습니다. REAL/SIM+REAL은 이 입력을 명시적으로 거부합니다.

기준 사진에서 최소 12개 일치 특징점, RANSAC 일치 비율 0.6, 충분한 사진 범위, 재투영 오차 2 px 이하를 확인합니다. 반복된 같은 프레임은 확인 횟수에 포함하지 않습니다. 사진 소실·시간 지연·충돌·도달 한계 등은 정지 조건입니다. 사진 검출은 사진 추종 모드를 선택했을 때만 실행하며 기존 마커 처리에 항상 비용을 추가하지 않습니다.

등록 사진과 설정은 `.delivery/kahl_screen_reference.png`, `.delivery/d455_photo_screen.json`에 로컬 저장합니다. 사진의 지정 중심은 `(318,111)` px이며 제품 카드의 좌상단을 기준으로 합니다. 다른 제품 사진은 이 기준을 그대로 사용할 수 없습니다. 제공된 파일은 저장소에 업로드하지 않았습니다.

검증: `.venv-vision\Scripts\python.exe -m unittest tests.test_photo_screen.PhotoVisionTests`, `py -3 -m unittest tests.test_photo_screen.PhotoControlTests`, `py -3 tools/moma_vision_smoke.py --camera --photo-screen-test`. 생성 화면의 원근·크기 변화와 제공된 제품 사진에서의 중심 추정, SIM 삽입·30° 회전·자동 후퇴, 실기 입력 거부를 검증합니다. 실제 모니터를 D455로 촬영한 인식 성공률은 별도 확인해야 합니다.
