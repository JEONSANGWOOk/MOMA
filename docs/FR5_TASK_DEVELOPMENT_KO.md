# FR5 실기 작업 개발

장비/API 페이지의 **FR5 작업 개발**에서 별도 창을 엽니다. 이 화면은 입력 양식 편집, 현재 자세 티칭, 작업 순서 구성, 검증 및 실기 시험 실행을 제공합니다. 공식 FAIRINO Python SDK를 사용하며 기본 IP는 192.168.58.2입니다.

## 시작
1. 연결 설정에서 제어기 WebAPP 버전, 해당 버전에 맞는 공식 SDK 폴더 및 동작 허용 여부를 설정합니다.
2. REAL 모드에서 FR5 연결 / 상태 수신으로 관절과 TCP를 확인합니다. AMR 장착 시 AMR도 실기 제어로 연결되어 정지 상태를 수신해야 합니다. 고정형 FR5만 개발할 때는 작업 창의 고정형 FR5 단독 시험을 선택하면 AMR 연결 없이 실행할 수 있습니다. 단독 시험은 AMR이 연결된 상태에서 차단됩니다.
3. 위치·그리퍼·입출력 API 탭에서 작업 이름을 지정합니다. MoveJ/MoveL 선택 후 현재 자세 티칭 → 작업 등록/갱신을 누릅니다. tool/user 좌표계 번호와 속도를 실제 설정에 맞게 수정합니다.
4. 그리퍼/진공 출력과 센서 입력을 작업으로 등록합니다. 작업 프로그램 탭에서 템플릿 생성 또는 작업/대기 단계를 추가합니다.
5. 프로그램 등록 → 실행 전 검증 → 라이브러리 저장을 누릅니다. 미등록 참조가 있는 초안도 저장할 수 있지만 실행은 차단됩니다.
6. 저장 후 FR5를 다시 연결합니다. 선택 단계 시험으로 한 단계를 시험하거나 프로그램 실행으로 전체 작업을 수행합니다. 실제 이동/출력 전 화면에서 확인합니다.

입력 양식의 0 좌표는 실제 작업 좌표가 아닙니다. 템플릿은 좌표 없이 작업 이름만 정의하므로 모든 작업점을 등록해야 합니다. 티칭은 최신 정지 자세만 사용합니다. SDK/툴/워크 좌표 및 실제 장치 동작은 현장에서 확인해야 합니다.

## API 작업
- MoveJ: target 관절 각도 6개[도], tool/user 0~14, vel 속도 비율[%].
- MoveL: target X/Y/Z[mm], RX/RY/RZ[도].
- SetDO / SetToolDO: id 제어함 0~15 / 툴 0~1, status 0 또는 1.
- WaitDI / WaitToolDI: 같은 채널 범위. 현재 입력이 status와 일치할 때만 완료합니다. 프로그램의 timeout_s가 대기 제한입니다.
- 대기 단계: wait_s만 지정. 작업 단계의 operation은 등록된 API 작업 이름입니다.

예를 들어 `grip_close`를 실제 그리퍼/흡착기 출력 채널에 맞는 SetDO/SetToolDO로 등록하고 `grip_confirm`을 파지/진공 센서 WaitDI로 등록합니다. 출력 API 접수 성공만으로 물체 파지를 보장하지 않습니다. 채널과 0/1 개폐 논리는 장치마다 다릅니다. 현재 기능에는 전동 그리퍼 전용 MoveGripper나 힘 제어 API가 포함되지 않습니다.

## 템플릿
- 픽앤플레이스: 안전 자세 → 개방 → 집기 접근/접촉 → 파지/센서 확인 → 배치 접근/접촉 → 개방 → 안전 자세.
- 도어 열기: 핸들 접근/파지 → 센서 확인 → 래치 조작 → 티칭한 호 궤적 점 3개 → 놓기/후퇴. 필요에 따라 이동점을 추가합니다. 문 형상 자동 추정·힘 제어·자동 충돌 회피는 포함되지 않습니다.
- 자재 공급: 장비 준비 입력 → 자재 파지/확인 → 장비 접근/삽입 → 놓기 → 공급 완료 출력 → 안전 자세.

`examples/fr5_task_templates.json`을 가져오면 위 세 초안을 불러옵니다. 가져오기는 화면 초안만 바꾸며 라이브러리 저장 전에는 실행 설정을 변경하지 않습니다. 내보내기는 작업/프로그램만 포함하고 IP·SDK 경로·실기 동작 허용 설정을 포함하지 않습니다.

## AMR 미션과 보고서
미션 Arm Action의 operation에 프로그램 이름을 지정하면 실행 전에 개별 단계로 확장합니다. 각 단계는 성공/실패/시간 제한과 루프별 보고서에 기록됩니다. 프로그램 실패 시 뒤의 작업은 실행하지 않습니다. 안전 자세가 실측으로 확인되어야 AMR의 다음 주행을 허용합니다. 미션 중 AMR 정지 상태/제어 연결이 소실되면 FR5 정지를 요청합니다.

FR5 정지는 로봇 StopMotion을 요청합니다. 디지털 출력을 자동 반전하지 않습니다. 물체 낙하 등을 피하기 위해 실패 시 그리퍼/진공 해제는 현장 장치의 안전 논리에 맞춰 설계해야 합니다. SIM FR5 관절 이동은 기존 MoveJ만 지원하며, MoveL 역기구학과 이 작업 프로그램의 I/O 물리 시뮬레이션은 구현되지 않았습니다. 오프라인 편집/검증은 가능합니다.
