# 실기 수동 재배치

Python 프로그램을 재시작하고 `실기 · 제어`로 연결한 뒤, 상단 연결 영역의 `수동 재배치`를 누릅니다. 기존 운행 화면의 자기위치 재배치 카드도 그대로 사용할 수 있습니다.

1. 실제 로봇을 정지한 상태에서 창의 X/Y(m), 방향 θ(도)를 지정하고 `입력 좌표로 재배치 요청`을 누릅니다. 확인 창에 표시된 값을 검토한 뒤 실행합니다.
2. 또는 `지도에서 위치·방향 지정`을 누르면 운행 2D 지도로 전환합니다. 실제 위치에서 누른 채 실제 방향으로 드래그하고 요청 좌표를 확인합니다.
3. 로봇의 재추정 결과와 LiDAR/지도 및 위치 신뢰도를 확인한 뒤 `정합 확인 후 위치 확정`을 누릅니다. 기존 운행 카드의 `위치 확정 (2003)`도 동일합니다.
4. 잘못 지정했다면 `재배치 취소` 또는 운행 카드의 `취소 (2004)`를 누릅니다.

기존 `relocate`(2002), `confirm_loc`(2003), `cancel_reloc`(2004) 경로를 사용합니다. theta 입력은 도 단위이며 전송 시 라디안으로 변환합니다. SIM·조회 전용·연결 해제·맵 생성 중에는 시작할 수 없습니다. 지도 지정 이후 연결 상태가 달라져도 전송 전에 재확인합니다. 이동 목적지를 보내는 기능이 아니라 실제 로봇의 자기위치 추정을 갱신하는 기능입니다. 창을 닫는 것만으로 재배치 취소 명령을 보내지는 않습니다.

개발 검증은 입력값 검사와 UI 생성만 수행했으며 실제 로봇 재배치·확정 명령은 전송하지 않았습니다.
