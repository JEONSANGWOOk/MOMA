# 로봇팔 그리퍼 / 충돌 / 픽앤플레이스 SIM

로봇팔 개발 → 오른쪽의 **그리퍼 / 물체 / 충돌** 탭에서 사용합니다.

## 실행 방법

1. safe_pose를 선택하고 SIM에서 실행해 TCP를 아래로 향하게 합니다.
2. 2지 그리퍼 또는 전동 1포트 진공을 선택합니다.
3. 픽앤플레이스 데모를 누르면 박스/판넬, 두 지지대와 SIM 픽앤플레이스 프로그램이 생성됩니다.
4. 동작 프로그램 탭에서 SIM 재생을 실행합니다. 파지 ON → 파지 DI 확인 → 들기 → 옮기기 → 내리기 → OFF → 해제 DI 확인 → 후퇴 순서로 움직입니다.

직접 작업을 만들려면 물체 크기·중심 자세·질량·마찰·흡착 표면을 설정하고 물체 추가를 누릅니다. obstacle은 고정 장애물입니다. 물체 좌표는 arm base 기준 mm/도입니다. 기존 관절 티칭/MoveJ/MoveL 프로그램에 SetDO 또는 SetToolDO와 WaitDI/WaitToolDI를 조합합니다. 기본 신호는 ToolDO 0 / ToolDI 0입니다. 물리 설정에서 신호 bank와 채널을 바꿀 수 있습니다. 그리퍼가 없으면 기존 수동 DI 값을 변경하지 않습니다.

## 물리량

2지: 최대 개구 폭, 개폐 속도, 양쪽 조 합계 수직력, 그리퍼·물체 마찰계수, 도구 질량, 허용 총하중과 안전계수를 반영합니다. 마찰 지지력은 합계 조 힘 × 더 낮은 마찰계수로 계산합니다.

진공: 컵 지름, 최대 진공압, 펌프 시정수, 해제/누설 시정수, 실링 효율과 표면 평탄성·기밀성을 반영합니다. 압력은 1차 응답으로 변하고 흡착력은 압력 × 면적입니다. 컵보다 작은 면, 비흡착 표면, 기울어진 면 또는 접촉하지 않은 상태에서는 파지하지 않습니다. OFF 후에는 압력이 감소해 지지력이 부족해질 때 놓습니다. 수직 지지력과 마찰에 따른 전단 한계를 확인합니다.

이동 가속도에 따른 하중과 중력, 물체 질량+도구 질량의 허용하중을 확인합니다. 힘 부족·과하중 시 떨어지고 DI가 OFF 됩니다. 놓인 물체에는 중력이 작용하며 바닥/지지대 위에 안착합니다. 상태·힘(N)·진공(kPa)·개구(mm)와 파지/해제/충돌 이벤트를 표시합니다.

도구의 장착면 Z 오프셋은 mount_offset_m입니다. 공식 FR5에서는 URDF 말단 링크 메시의 끝을 기준으로 추정하며 실측 보정할 수 있습니다. 기존 MoveJ/MoveL 좌표는 URDF 말단 프레임을 기준으로 유지합니다. 실제 tool/user 좌표는 별도 보정이 필요합니다.

## 충돌 표시

URDF 링크와 도구, 가상 물체를 회전 경계 박스(OBB)로 검사합니다. 회색 선은 검사 영역, 노란색은 여유 거리 이내, 빨간색은 충돌/충돌 예상입니다. 다음 0.25초 목표 자세의 충돌도 미리 확인하고 빨간 반투명 자세로 표시합니다. 관절 변경 중간 자세도 검사하고 위험한 이동을 적용하기 전에 차단합니다. 수동 관절 조절에도 적용됩니다. thin obstacle 크기에 따라 검사 간격을 줄입니다.

바닥 충돌은 기본 ON입니다. self_collision=true로 비인접 링크끼리의 검사를 추가할 수 있습니다. 경계 박스는 메시보다 큰 보수적 영역이므로 자체 충돌은 기본 OFF입니다. 물체와 손가락/흡착컵의 파지 접촉은 허용하며 팔 본체·고정 장애물과의 충돌은 차단합니다. 운반 물체도 장애물·바닥 검사를 합니다.

이 기능은 동작 개발용 공학 근사 모델입니다. 완전한 강체 접촉·관절 토크·충격·회전 낙하·변형 해석 엔진은 아닙니다. 실제 FR5 안전제어 및 실물 그리퍼의 드라이버 검증과 구분해 사용합니다. UI 신호와 물체는 독립 SIM 상태이며 실제 로봇에 명령을 보내지 않습니다.

설정 저장으로 도구 물리량과 물체 장면을 보관합니다. URDF를 바꿔도 장면·도구 설정을 유지합니다. SIM 실행 이력에 단계별 결과 및 물리 이벤트 시간이 포함됩니다.
