# 실기 장애물 미션 대응

지도/제어의 주행 장애물 대응에서 `실기 미션 장애물 대기 / 자유 경로 재탐색 / 패스`를 켠 뒤 미션을 시작합니다. 기본은 꺼짐이며 실행 중 변경하지 않습니다. 설정한 대기 시간과 재탐색 한도를 사용합니다.

대기: 제어기 기존 주행 유지, 장애물 해제 후 진행. 정지: 취소 완료 후 작업을 중지하고 새 미션 필요. 회피/재탐색: 대기 후 3003 취소 ACK와 최신 terminal 상태/정지 확인 후 3050 자유 주행 요청. 한도 초과 시 취소 완료 후 목적지 패스, 다음 목적지 이동. 거부/불확실 응답은 실패로 처리하며 임의 재전송하지 않습니다. 미션 보고서에 이벤트 기록.

현재 BLOCKED 지점의 좌표 변화를 관측하며 움직임 감지/정체/판단 중으로 표시합니다. 이는 물체 ID 추적 또는 사람/AMR 분류가 아닙니다. 모르는 경우 동적 대기 시간을 적용합니다. 최신 LiDAR가 없으면 자동 재탐색하지 않습니다.

실제 회피 경로 생성은 SEER 제어기의 자유 주행 기능입니다. 펌웨어/자유 주행 설정 지원이 필요합니다. PC가 계산한 경로 강제 실행, 짧은 후진, 원래 라인 최단 복귀는 실기 미구현입니다. 조이스틱과 별개이며 Studio Path Nav 미션에만 적용됩니다. 현장 실기 시험은 미수행입니다.
