# 전시 화면

개발자 모드의 상단 전시 화면 버튼을 누릅니다. 현재 연결을 유지하고 3D 화면으로 전환합니다.

- 관람 화면: 3D 뷰, LIVE/SIMULATION 구분, 연결 상태, 배터리, 장애물/비상정지 상태.
- 운영 패널: 기존 연결/IP/모드, 내비게이션과 주행 제어 패널을 표시합니다. 연결/API, DI/DO, 문 설정도 기존 메뉴에서 사용할 수 있습니다.
- 운영 패널 닫기: 지도/제어의 3D 화면으로 복귀합니다.
- 전체 화면: 전체 화면 진입/해제. 일반 화면 버튼으로 나가면 진입 전 창 상태와 패널 배치를 복원합니다.
- 정지 버튼과 기존 Esc 정지는 유지됩니다. 소프트웨어 정지이며 하드웨어 비상정지를 대체하지 않습니다.

전시 화면 진입은 수동 누름 주행을 해제합니다. 연결이나 미션을 새로 시작하지 않습니다.
화면 모드는 자동 저장하지 않아 앱은 기존 작업 화면으로 시작합니다.
