# DualSense 자동 연동 / 복귀 버튼

Python을 재시작하고 컨트롤러를 선택한 뒤, 운행 화면에서 조종 대상 AMR, 수동 조작 및 DualSense 사용을 켭니다. 스틱 중앙에서 L1을 놓았다가 한 번 눌러 활성화합니다.

- ×(기본 2번): LM2 정지 상태에서 LM2→LM1 이동 및 기존 main2→main3 연동 시작. main3 전 2초 대기도 기존 경로를 사용합니다.
- □(기본 1번): LM1 정지 상태에서 LM2로 노드 이동. main2/main3를 별도로 실행하지 않습니다.
- ○(기본 3번): AMR 정지 요청 및 대기 중인 연동의 후속 실행 차단. 이미 실행 중인 로봇팔의 정지를 보장하는 버튼이 아니며 물리 비상정지 대체 기능이 아닙니다.

버튼 누름 상승 에지만 처리하므로 길게 눌러도 반복 실행하지 않습니다. 스틱 중앙, 최신 입력, 올바른 출발 노드, 정지 상태와 기존 팔 안전 인터록이 필요합니다. 잘못된 노드·주행 중·다른 작업 진행 중에는 요청을 차단합니다. 연결/포커스/실기 제어권 등 기존 조건도 유지합니다.

자동 실행으로 전환하면 스틱 수동 주행을 해제합니다. 자동 작업 종료 후에는 리모컨 자동동작 모드를 유지하므로 정지 상태에서 □로 복귀를 요청할 수 있습니다. ○ 정지, 컨트롤러 단절 또는 모드 설정 변경 후에는 다시 활성화해야 합니다. 자동 재개는 없습니다.

이 기능은 기존 시나리오를 호출하는 입력 버튼 추가입니다. 실제 충돌 원인을 수정한 기능이 아니며, 문제가 있는 실기 궤적을 반복 실행해서 검증하면 안 됩니다. 개발 확인은 모의 호출과 입력 게이트 테스트로 수행했고 실제 이동·팔 동작은 실행하지 않았습니다.
