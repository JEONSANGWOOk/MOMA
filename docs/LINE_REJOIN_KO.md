# 장애물 구간만 우회 / 원래 경로 복귀

메인 **지도 / 제어 → 주행 장애물 대응 · SIM**에 `장애물만 우회 / 원래 경로 최단 복귀 우선` 옵션을 추가했습니다. 기본 켜짐이며 설정을 저장합니다.

- 원래 노드 경로(직선 또는 곡선)를 임시 우회 경로와 별도로 보관합니다.
- 장애물이 있는 구간만 우회하고, 장애물 이후 처음 안전하게 복귀할 수 있는 원래 경로 지점을 탐색합니다. 복귀 이후 경로는 원래 경로 그대로 유지합니다. 직선 구간에서는 직진합니다.
- 주행 중 0.5초마다 현재 장애물 위치로 직접 복귀 가능 여부를 확인합니다. 가까운 원래 경로 투영 지점까지 안전한 직선 연결이 열리면 긴 임시 우회 경로를 줄여 바로 복귀합니다. 연결 및 진행 방향의 장애물과 이동체 충돌 가능성을 검사합니다.
- BLOCKED에서 현재 위치 우회를 먼저 시도하고, 불가할 때 짧게 후진한 뒤 목적지까지 크게 대각선으로 가지 않고 장애물 이후 원래 경로 복귀를 먼저 탐색합니다.
- 전체 노드 경로 탐색이나 다른 길 정책에서도 국소 우회 후 원래 경로 복귀를 먼저 시도합니다. 복귀 통로가 없으면 기존 다른 길 탐색 및 목적지 불가 처리를 사용합니다.
- 명시적 정지/대기 정책과 차체 충돌 검사는 유지합니다. 우회에 필요한 공간이 없으면 라인으로 강제 진입하지 않습니다.

복귀 지점은 샘플 기반 탐색과 현재 관측 위험도에 따라 선택하므로 수학적으로 전역 최단거리임을 보장하지 않습니다. 직선 연결이 안전하면 가장 가까운 투영점으로 복귀합니다. 곡선이면 원래 곡선을 유지합니다.

라인트레이싱을 넣을 때 이 원래 경로를 기준선으로 사용하고 임시 우회 후 기준선 추종으로 돌아가는 구조입니다. 실제 카메라/라인센서 피드백에 의한 라인트레이싱과 실기 자동 회복 명령은 이번 SIM 변경에 포함되지 않습니다.
