# 로봇팔 전용 3D 워크스페이스

왼쪽 WORKSPACE의 **로봇팔 개발**을 선택합니다. AMR 연결이나 실제 FR5 연결 없이 사용할 수 있습니다. 전용 시뮬레이터의 관절/작업/입출력은 AMR 시뮬레이터 및 실기 FR5 설정과 독립되어 있습니다.

## 3D와 관절
- 공식 FR5 모델을 설치하면 fairino5_v6 ROS2 URDF를 기본으로 사용합니다. 미설치 시 기존 경량 FR5 URDF를 사용합니다. 실제 제품의 정확한 기구학/충돌 모델 검증을 대신하지 않습니다.
- 마우스 왼쪽 드래그: 회전, 오른쪽 드래그: 이동, 휠: 확대/축소. 위/정면/측면/뒤/사선 및 원근/직교를 선택합니다.
- 관절 슬라이더 또는 각도 입력 후 Enter로 자세를 조절합니다. URDF 관절 범위를 검사합니다. 회전 관절은 도, prismatic 관절은 m입니다.
- 화면 아래 TCP는 현재 URDF 끝단 tool link의 위치[mm]와 RPY[도]입니다. 주황색 선은 TCP가 지나온 궤적입니다.
- URDF 가져오기로 독립 모델을 바꿉니다. URDF에 연결된 STL/OBJ 메시를 함께 배치하세요. 사용자 모델은 해당 모델의 joint와 끝단 link로 표시합니다. MoveJ/MoveL 개발은 6축 회전 관절 모델을 사용합니다.

## 자세 티칭과 직선 이동
1. 관절을 움직여 원하는 자세를 만듭니다.
2. 작업 이름을 입력하고 MoveJ 또는 MoveL을 선택합니다.
3. 현재 자세 / I/O 등록으로 작업을 등록합니다. MoveJ는 관절 6개, MoveL은 현재 모델 TCP 위치·자세를 저장합니다.
4. 등록한 작업을 목록에서 선택하고 선택 작업 시험으로 재생합니다.
5. TCP 목표 입력에 `X,Y,Z,RX,RY,RZ` 6개를 넣고 TCP 목표로 SIM 직선 이동을 누르면 수치 역기구학으로 직선 궤적을 계산합니다. 실패하면 관절을 움직이지 않고 실패 이력을 기록합니다. 이동 후 현재 자세를 티칭할 수 있습니다.

MoveJ는 관절 보간, MoveL은 TCP 직선 및 RPY 각도 보간/수치 역기구학으로 미리보기합니다. 작은 구간은 관절 보간으로 재생하며 약 1mm 수준의 수치 오차가 있을 수 있습니다. 선택한 FR5 URDF와 실제 장비 형식·TCP 설정이 일치하는지 현장 검증이 필요합니다. 실기의 속도/가감속/툴/워크 좌표계를 그대로 재현하지 않습니다. tool/user=0 외 설정은 변환 정보가 없으므로 SIM 실행을 차단합니다. 자가 충돌·외부 물체 충돌·물체 파지 물리·힘 제어는 포함하지 않습니다.

## 동작 프로그램
- 동작 프로그램 탭에서 기본 **관절 이동 예제**를 SIM 재생하면 바로 확인할 수 있습니다.
- 픽앤플레이스/도어 열기/자재 공급 템플릿은 작업 이름만 넣는 초안입니다. 작업들을 티칭한 후 실행하세요.
- 작업/대기를 추가하고 위/아래/삭제로 순서를 수정합니다. 시간 제한은 단계별 초 단위입니다.
- 프로그램 등록 후 SIM 재생, 일시정지/재개, 정지를 사용합니다. SIM 실행 이력에는 각 단계 성공/실패가 표시됩니다.
- SetDO/SetToolDO는 가상 출력만 바꿉니다. WaitDI/WaitToolDI는 가상 입력 확인을 기다립니다. 관절/티칭/I/O 탭 아래 **SIM 입력 변경**으로 센서를 시험합니다. 출력 변경이 입력을 자동으로 바꾸지 않습니다.
- 설정 저장으로 모델 경로, 관절, 작업 및 프로그램을 저장합니다. 재실행 시 복원합니다. 저장 전 현재 편집 중 프로그램은 프로그램 등록으로 등록해야 합니다.

## 실기 작업 개발과 파일 공유
- API 작업 가져오기는 현재 FR5 실기 개발 라이브러리를 독립 SIM으로 복사합니다. 실기 설정을 덮어쓰지 않습니다.
- 라이브러리 가져오기/내보내기로 기존 FR5 작업 파일을 공유할 수 있습니다. SIM 내보내기에는 모델 경로와 hardware_verified=false를 표시하며 실기 동작 허용 설정은 포함하지 않습니다.
- 실기 API 개발 버튼은 이전 FR5 API 개발 창을 엽니다. 실제 티칭/툴·워크 좌표/속도/장치 채널을 검증한 뒤 실기 창에서 별도로 실행합니다. 로봇팔 워크스페이스의 관절 조절·SIM 재생은 실기로 전송되지 않습니다.
