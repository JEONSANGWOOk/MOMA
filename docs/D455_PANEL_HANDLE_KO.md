# 사진 기반 KAHL-1057-B(R) 손잡이·열쇠

첨부 사진의 긴 은색 테이퍼 손잡이, 원형 받침판과 옆 걸쇠, 상단 원형 키 실린더, 은색 중공 원통 열쇠와 평평한 키 머리를 공통 3D 모델로 적용했습니다. MOMA 통합 화면과 별도 판넬 SIM·REAL·SIM+REAL 화면에서 같은 모델을 사용합니다. **사진 모델 미리보기 (SIM)**는 가상 기준판을 선택하고 손잡이 쪽을 확대합니다. 실제 D455 영상과 인식 수치는 이 미리보기와 독립적으로 계속 표시합니다. 실제 제어 모드에서는 미리보기 전환을 차단합니다.

사진에는 치수 도면과 정확한 키 코드가 없으므로 `config/panel_handle.json`의 수치는 모두 SIM 추정값입니다. 파일을 변경하고 프로그램을 다시 시작해 손잡이 길이, 키 외경·내경·길이, 구멍·중앙 핀 반경과 삽입 깊이를 맞출 수 있습니다. 기본값은 손잡이 길이 185 mm, 키 외경 8 mm·내경 6 mm, 원형 구멍 외경 9 mm·핀 직경 4.8 mm, 키 원통 길이 30 mm, 삽입 깊이 22 mm입니다. 실제 제품 규격으로 확정한 값이 아닙니다. 키 코드 홈과 실린더 핀 배열은 참고 표현입니다.

SIM 충돌은 중공 키의 내·외경과 중앙 핀·바깥 벽의 여유를 검사합니다. 기울어짐으로 발생하는 간섭도 반영합니다. 키홀과의 접촉 검사만 원통형 여유 검사로 처리하며, 로봇·그리퍼·손잡이·판넬·뒷면·바닥의 기존 충돌 검사는 유지합니다. 완전 삽입, 횡방향·축 오차와 키 일치 조건 확인 후에만 기존 90° SIM 회전을 허용합니다. 이 결과의 해제 표시는 가상 키 실린더 상태입니다. 실제 이중시건, 자동잠금, 손잡이 회전·문 열림 센서까지 검증한 결과는 아닙니다.

외형 설정은 실제 FR5 명령의 카메라/열쇠 TCP 보정 파일을 변경하지 않습니다. 실제 삽입 깊이·회전량은 실측 보정 파일을 사용하며, 사진 모델의 추정값을 자동 적용하지 않습니다. 실제 손잡이·키 치수와 키 끝 TCP를 측정해서 보정해야 합니다.

첨부 사진은 이 노트북의 `.delivery/kahl_1057_reference.jpg`에서 참고용으로 표시합니다. 원본 사진은 GitHub에 포함하지 않습니다. 다른 PC에서는 사진 없이 동일한 코드 기반 3D 모델을 표시합니다.

검증: `py -3 -m unittest tests.test_panel_handle_model tests.test_key_panel tests.test_key_panel_twin` 및 `py -3 tools/d455_key_panel.py --smoke`. `--smoke`는 실제 이동 명령 없이 새 중공 키로 삽입·회전 주기를 검사합니다.
