# 제어 PC 없는 실기 동작 재생과 마지막 지도

## 지금 사용할 수 있는 지도

Python을 시뮬레이션 모드로 연결한 뒤 `main1/2/3 · 오프라인` → `마지막 실기 맵 → SIM`을 누르세요. 이전 4011 다운로드의 사용자 폴더 maps/*.smap을 읽습니다. 포인트 클라우드·노드·각도·경로를 로컬에서 파싱하고 SIM 모델에 적용하며 제어 PC에 연결하지 않습니다. LM2가 있으면 SIM 시작 위치를 LM2로 맞춥니다. 진행 중인 SIM 작업이 있으면 지도 전환을 차단합니다. 앞으로 지도 수신 시 last_real_map.json에 마지막 파일을 별도로 기억합니다.

## 실기와 동일한 관절 궤적을 쓰려면

원격 Python 코드를 그대로 import하거나 실행하지 않습니다. 해당 코드는 제어 PC SDK, 포인트 데이터, 도구/좌표계, 카메라/ArUco 결과에 의존하기 때문입니다. 현재 이 PC에는 원격 전체 포인트 데이터와 완료된 실행 궤적이 없고 제어 PC도 연결 불가하므로 지금 동일한 동작을 복원했다고 할 수 없습니다.

제어 PC를 사용할 수 있을 때 한 번 다음을 수행하세요.

1. 이 버전 Python의 실기 3D 화면을 열고 실제 지도와 설비 배치를 확인합니다.
2. 프로그램의 시나리오 버튼 또는 LM2→LM1 연동으로 main1/main2/main3를 실행합니다. 저장만을 위해 프로그램이 실제 동작을 자동 실행하지는 않습니다.
3. 정상 종료한 시나리오의 표시 관절·AMR 좌표·베큠 출력·지도 이름·설비/마운트 위치가 사용자 폴더 `offline_scenarios/mainN.json`에 자동 저장됩니다. 화면이 그려지지 않았거나 실행이 실패하면 기존 정상 기록을 덮어쓰지 않습니다.
4. 이후 제어 PC 없이 SIM에서 마지막 지도를 불러오고, 재생 소스를 recording으로 둔 채 SIM main1/main2/main3를 실행합니다. 다른 PC의 JSON은 `실기 실행 기록 JSON 가져오기`로 옮길 수 있습니다.

SIM의 기본은 기록 재생입니다. 기록이 없으면 실행을 차단하며 예제로 대체하지 않습니다. program을 명시적으로 선택한 경우에만 기존 로컬 프로그램/예제를 실행합니다. 이것은 실기와 같은 궤적이라고 표시하지 않습니다.

## 문·패널 검증의 범위

기록은 문 각도를 강제로 재생하지 않고, 저장된 관절 궤적과 설비 좌표에서 기존 후크/롤러 문 추종을 다시 계산합니다. 베큠 출력 2·4/블로우 3·5로 패널 표시를 재현합니다. 모델·지도·원점·도구 배치가 실기와 달라지면 결과도 달라집니다. 영상·ArUco 재인식 성공, 실제 힘·마찰·충돌 안전성을 검증하는 것은 아닙니다. 실제 main2/main3 코드의 변경도 기존 궤적 기록에 자동 반영되지 않으므로 변경 후에는 새로 기록해야 합니다.

기록 재생 중에는 독립 팔 시뮬레이터의 자동 tick을 중지하고 저장 관절을 표시합니다. SIM 팔 정지, 모드/지도/모델 변경 시 재생을 중단합니다. LM2→LM1 연동은 main2/main3 기록이 모두 있는지 확인한 뒤 출발하며, 속도 상승 → main2, 도착과 main2 종료 → 2초 → main3 순서입니다.

검증: JSON 검증·잘못된 기록 차단·기록 누락 시 차단·저장/로드·네트워크 금지 상태의 관절/베큠/차체 재생·실기 SMAP의 노드/방향 보존을 자동 테스트했습니다. 실제 원격 시나리오와의 동일성은 원본 실행 기록 부재로 검증하지 못했습니다.
