# 전기 판넬 SIM·REAL 통합 실행

기존 MOMA 프로그램과 ArUco 영상까지 함께 사용하려면 `MOMA_Vision.cmd`를 실행하세요. [MOMA 통합 설명](MOMA_VISION_KO.md)을 참고하세요.

`D455_Key_Panel_Twin.cmd`를 실행합니다. 자동 동작 없이 SIM 모드로 열립니다. 기존 `D455_Key_Panel.cmd`도 같은 통합 화면을 사용하며 SIM 데모를 자동 시작합니다.

| 모드 | 동작 |
|---|---|
| SIM | 가상 판넬에서 정렬·22 mm 삽입·30° 회전 시험. 실기 이동 명령 없음 |
| REAL | 실제 D455와 실측 보정값으로 FR5 제어. 수신한 실제 관절 자세 표시 |
| SIM+REAL | 동일한 실측 TCP 목표를 먼저 가상 역기구학으로 계산하고 FR5에 전송. 실제 관절과 SIM 예측을 겹쳐 비교 |

1. 기존 D455 마커 인식 창을 실행하고 두 마커를 함께 관찰합니다.
2. 통합 화면에서 SDK 폴더와 FR5 주소 `192.168.57.2`를 확인합니다.
3. 연결하기 전에 실측 보정 JSON을 불러옵니다. 연결 상태에서는 보정 파일을 변경할 수 없습니다.
4. **상태 연결**로 실제 상태를 읽고 REAL 또는 SIM+REAL을 선택합니다. 연결과 모드 변경만으로 로봇이 움직이지 않으며 작업 중에는 모드를 바꿀 수 없습니다.
5. **선택 모드 작업 시작**을 누릅니다. 접촉 옵션을 끄면 구멍 앞 5 mm에서 접근 시험을 끝냅니다. 삽입·회전은 접촉 옵션과 검증된 힘/토크 보호 설정이 필요합니다.
6. **SIM + FR5 정지**는 두 실행을 함께 중지하고 실제 정지 요청을 보냅니다. 통신 장애 시 물리 정지는 확인할 수 없습니다. 정지 후 실기는 재연결해야 합니다.

실측 보정에는 고정 카메라→로봇 베이스, 두 마커→열쇠구멍, 열쇠 끝 TCP, 작업 범위, 삽입 깊이·회전량, 실제 제어기/SDK 버전 및 접촉 보호 설정이 필요합니다. [실기 보정 설명](D455_KEY_PANEL_REAL_KO.md)을 참고하세요. 화면의 **SIM 전용 값**은 실제 로봇의 속도·구멍 좌표를 변경하지 않습니다.

SIM+REAL의 파란 반투명 로봇은 가상 예측이고 원래 색 로봇은 실제 수신 관절입니다. 노란 점은 SIM 열쇠 끝, 초록 점은 실제 TCP입니다. 오른쪽에 TCP 거리·자세 차이와 실제 힘/토크를 표시합니다. 수신 데이터를 SIM 값으로 덮어쓰지 않습니다. 실제 상태나 영상이 오래되면 작업을 중지합니다. 가상 역기구학 실패 시 해당 실기 이동 명령을 차단합니다.

가상 모델은 연결/작업 시작 때 실제 관절과 TCP를 이용해 표시용 도구 변환을 맞춥니다. 이 맞춤은 카메라 보정이나 실제 TCP 보정을 대신하지 않으며 이후 수신마다 다시 맞춰 오차를 숨기지 않습니다. 판넬·그리퍼·열쇠 외형은 참고 형상입니다. SIM+REAL은 기구학 비교 기능이며 실제 주변 환경의 완전한 충돌 검사나 삽입 접촉 역학·힘 제어 검증을 제공하지 않습니다. 실기 자동 후퇴와 잠금 센서 확인은 아직 지원하지 않습니다.

판단·모드·목표·실제/가상 TCP 차이·중지 사유는 `.delivery/d455_key_panel/decisions.jsonl` 및 `decisions.txt`에 기록됩니다.

검증: `py -3 -m unittest tests.test_key_panel_twin tests.test_key_panel_real tests.test_fairino tests.test_arm_sync tests.test_render_performance`. `--smoke-ui`는 연결 없는 화면 시험, `--smoke-compare`는 명시적인 합성 피드백으로 겹침 표시만 시험하며 실제 명령을 보낼 수 없습니다. 실제 로봇 동작은 네트워크·보정 준비 후 현장에서 확인해야 합니다.

30° 회전 확인 후 열쇠 방향을 유지하면서 자동 후퇴합니다. SIM은 슬롯 앞 100 mm, REAL은 보정 파일의 standby_mm까지 후퇴한 뒤 완료합니다. REAL의 이전 90° 보정 설정은 사용할 수 없으며 turn_deg를 실물 기준으로 30° 이하로 확인해야 합니다. 기존 힘/토크·정렬·영상·충돌 보호는 후퇴 중에도 유지됩니다.
