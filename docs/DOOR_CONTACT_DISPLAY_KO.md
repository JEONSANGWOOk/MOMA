# 실제 로봇 동작과 3D 문 표시 연동

3D 문 열기 / 닫기 → 로봇 동작 연동 시작.
이 버튼은 수동 문 표시와 웹캠 표시를 해제하고 실제 관절 기반 추정을 켭니다.
LiDAR 설비 배치 확정, 최신 AMR 위치와 FR5 관절 피드백, 공식 로봇팔 및 해당 엔드이펙터 모델이 필요합니다.

실측 관절 FK로 J6 위치/방향을 계산한 뒤 후크 끝과 롤러 중심을 CAD 좌표로 변환합니다.
손잡이 근처 후크는 힌지 원호 추종, 문틀 CAD 메시 표면과 롤러 크기 기반 접촉은 열리는 방향으로만 추종합니다.
이탈/피드백 지연/위치 점프 시 추종을 해제하고 마지막 추정 각도를 유지합니다.

롤러는 고정 한 점 대신 문 CAD 삼각형 표면의 최근접점을 사용합니다. BVH로 후보 표면을 제한하고, 샘플 사이 이동 경로를 검사해 얇은 문틀을 건너뛰는 현상을 줄입니다.
후크 해제와 롤러 접촉을 같은 샘플에서 처리하며 현재 문 각도를 유지합니다. 롤러 반경은 실제 표시 모델의 Polymer 부품 외곽 치수에서 얻은 구형 근사치입니다. 웹과 데스크톱 모두 표시 모델의 회전을 적용합니다.
표면 침투는 힌지의 여는 방향으로 해소하고, 롤러 후퇴로 문을 당겨 닫지 않습니다. 표시 각속도 상한은 2 rad/s입니다. 모델 반경·추정 각속도·잔여 겹침량은 웹 문 설정에서 확인할 수 있습니다.
CAD/도구 배치와 실제 센서 좌표는 현장에서 보정해야 합니다.
후크 진입/걸림을 센서로 확인하는 기능이나 엔드이펙터 전체 형상의 충돌·변형 해석은 아닙니다.
문 질량·관성·힌지 마찰·잠금·힘/토크는 반영하지 않습니다.
따라서 표시 각도는 실제 개방 확인이나 로봇 주행/접촉 안전 판단에 사용할 수 없습니다.
실제 문 각도 확인은 별도 센서/카메라 측정이 필요합니다. 로봇 명령은 전송하지 않습니다.
