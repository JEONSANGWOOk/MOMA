- 최신 저장 표시 보정은 (-0.04m, +0.02m, +0.5도), 점수 0.83125였습니다. 앞서 낮은 점수 설정을 초기화한 이후에도 실행 중인 프로그램 또는 사용자 정합 조작으로 새 설정이 저장된 상태였습니다. 저장 주체는 로그만으로 확정하지 않습니다.
- 원본 1009 극좌표를 install_info와 실제 AMR 위치로 변환한 점군은 표본 기준 맵 점으로부터 10cm 이내 비율이 laser1 75%, laser2 65.6%, 최근접 거리 중앙값 1.4cm/6.3cm였습니다. 이는 현장 오차 보증이 아닌 정지 표본 비교입니다.
- 두 센서의 upside=true를 보고 임의로 스캔 각도를 반전하면 일치 비율이 13.1%/17.5%로 악화됐습니다. 이미 반환된 beams의 방향을 추측해 반전하지 않았습니다.
- 기존 코드는 표시 정합을 로봇 위치/방향, 미션 미리보기, 노드 판정에 적용했습니다. 라이다/장애물 레이어는 수신 형식에 따라 적용하거나 생략하므로 서로 다른 좌표가 표시될 수 있었습니다.
- 이 경로는 11월 7일 게시본에도 존재했습니다. 오늘 마커 기능이 실제 AMR 위치를 변경한 증거는 없습니다. 다만 기존 표시 보정 경로가 남아 있어 앞선 설정 초기화만으로는 재발을 막지 못했습니다.

## 수정

- 지도, 로봇 위치/방향, 라이다, 장애물, 노드 판정 및 미션 미리보기를 원본 MAP 좌표로 통일했습니다.
- 극좌표 센서 장착 변환과 AMR→MAP 변환은 기존 파서에서 한 번만 수행합니다. 이후 표시용 위치/각도 보정을 추가하지 않습니다.
- 3D와 Isaac 출력도 원본 MAP 좌표를 사용합니다. 마커 기반 설비 배치는 이 좌표에서 CAD에만 적용합니다.
- _lidar_map_xy는 구 호출부 호환용 항등 변환이며, 저장 정합값은 로드하지 않습니다. 이전 고득점 값도 실제 위치/노드 판정을 변경할 수 없습니다.
- 자동 표시 정합은 실행하지 않고 수동 버튼은 'LiDAR 정합 진단'으로 변경했습니다. 계산 후보는 보고만 하고 저장/적용하지 않습니다. 초기화 버튼은 남은 설정을 0으로 정리합니다.
- 사용자 정합 설정 전체를 백업한 뒤 비활성화했습니다. 파일: `%USERPROFILE%/.seer_amr_console/lidar_map_alignment.bak-map-frame-20261109-114620.json`.

실행 중인 Python은 메모리에 예전 코드를 유지하므로 반드시 종료 후 재시작해야 합니다. 사용자의 현재 작업을 임의 종료하지 않았습니다. 재시작 후 RoboShop의 위치/방향과 Python을 비교하세요. 남는 불일치는 새 화면/로그로 확인해야 하며 실제 로봇 위치 추정 문제까지 이 변경으로 해결됐다고 단정하지 않습니다.
