# 최종 업데이트 · 2026-11-10

## 포함된 기능

- Isaac 실시간 미러: 최대 30Hz 프레임 발행, 공통 80ms 자세 버퍼와 회전 SLERP, 1080p / DLSS Quality / 모션 블러 OFF.
- 후크·롤러·문 동기화: 화면의 동일 보간 자세 사용, DO7 단계별 열기/닫기, 접선 기반 롤러 추종, OFF 후 잔여 닫기.
- ArUco·티칭 기반 설비 배치, 손잡이 앞면과 후크 형상의 깊이 보정, 공유 힌지 기준 및 CAD 겹침 진단.
- 독립 FR5 공식 SDK 읽기 전용 IO 수신, 베큠 패널 표시, 전체 작업 녹화·설비 배치 분석.
- 오프라인 작업 재생과 마지막 실기 지도 활용, 지도·LiDAR·로봇 좌표 표시의 MAP 기준 통일.
- 제어 PC용 선택적 마커/DO7 피드백 패치와 적용 안내.

## 실행 / 적용

Windows에서 저장소 폴더의 `run_windows.bat`를 실행합니다. Python 3D 화면과 Isaac 연결은 `tools/isaac_mirror/README_KO.md`를 참고하세요.

기본 `config/isaac_door_physics.json`은 `door_motion_mode: mirror`입니다. 실험 물리는 `physics` 설정과 연결 창 체크를 함께 사용하고 Isaac을 다시 실행해야 합니다. 실제 로봇 명령 없이 화면을 확인하는 미러 모드가 기본입니다.

## 범위와 제약

문 각도·배치는 로봇 자세와 CAD에 따른 표시용 추정입니다. 실물 문 각도·힘을 독립 측정해 검증한 물리 모델이 아닙니다. 물리 모드의 질량·마찰 등은 미측정 초기값이며, 충돌체 설정은 비관통 보증이나 실기 충돌 정지 제어를 의미하지 않습니다.

현장 SDK 경로·SSH 키·개인 설정·실행 로그·카메라 영상·취득 지도/작업 기록은 배포본에 포함하지 않습니다. SDK 설치와 읽기 전용 터널 설정은 `docs/FR5_DIRECT_SDK_SETUP_KO.md`를 참고하세요.

물리량 자동 식별은 향후 확장 범위입니다. 독립 문 각도와 힘/토크 데이터 및 별도 검증 궤적을 확보해야 합니다.

## 배포 검증

저장소 전체 836개 테스트를 실행했습니다. 834개 통과, 1개 건너뜀, RealSense SDK 패키지 누락 1개를 확인한 뒤 `pyrealsense2` 설치 후 해당 모듈 5개 테스트가 통과했습니다. 설치된 Isaac Sim 6.2 USD 라이브러리에서 문 바디·힌지·질량·마찰·제한 및 구동 보조 설정 검사도 통과했습니다. 실제 로봇 동작이나 물리 Play를 실행한 검증은 아닙니다.
