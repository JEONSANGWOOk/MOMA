# SIM/실기 기능 통합 현황

2026-10-04, v1.17. 모든 SIM 기능의 실기 동일 동작은 아직 완료되지 않았습니다.

## 이번에 구현한 공통 기반
- 실제 제어기의 BLOCKED 감지/해제, 비상정지, Task, 충전, 모터, 오류/경고 상태 전환을 미션 보고서의 해당 루프·단계에 기록합니다.
- 위치·속도처럼 매 순간 바뀌는 값을 이벤트로 계속 추가하지 않으며 같은 상태의 중복 기록을 제한합니다.
- 새 루프/단계에서는 기준 상태를 다시 기록합니다.
- JSON/TXT 보고서에 실행 환경 REAL/SIM과 수신된 모델/펌웨어 정보를 구분합니다. 실기 검증 여부는 false로 표시합니다.
- 로봇 운영 정보 → 실기 연동 현황에서 기능별 SIM/실기 구현 및 남은 확인 항목을 봅니다. 연동 현황 JSON을 저장할 수 있습니다.

## 이미 코드에 있는 실기 연동
위치·상태 조회, Station 목적지 주행(3051), 일시정지/재개/취소(3001/3002/3003), 수동 JOG/STOP(2010/2000), 지도 전송/로드(4010/4011/2022), FR5 공식 SDK 작업/피드백, 등록 장비 DI/DO, 충전 노드 이동/충전 상태 확인, 미션·루프·보고서가 있습니다. API 연결 코드의 존재는 해당 로봇에서 같은 동작을 검증했다는 뜻이 아닙니다.

## 아직 동일하게 연결되지 않은 부분
- PC의 자유 공간 우회/원래 직선 복귀/관측 기반 경로 비용은 SIM 엔진을 제어합니다. 실기는 3051 목적지 주행으로 제어기의 내비게이션을 사용합니다.
- 장애물별 대기/우회 설정은 현재 SIM 설정이며 실기 제어기에 전송하지 않습니다.
- 신규 장애물 추적과 동적/정적 분류는 SIM 관측 입력입니다. 실제 LiDAR에서 기존 지도와 신규 물체를 구분하고 분할/연결/추적하는 입력 계층이 필요합니다.
- 실제 목적지 패스는 취소 요청의 완료, 기존 명령의 종료, 현재 Task/목표 확인, 다음 미션의 시작을 동기화해야 합니다. SIM 패스 로직을 그대로 복사하지 않습니다.
- 통과 노드 무정차, 경로/좌표 주행, 실기 회피 설정은 대상 펌웨어의 지원 명령과 옵션을 확인해야 합니다.
- 실기 수동 장애물 인터록은 제어기 BLOCKED 상태를 사용합니다. PC의 SIM 발자국 검사와 동일한 실기 LiDAR 충돌 계산을 제공하는 것은 아닙니다.

## 다음 실기 연동에 필요한 자료
1. AMB-CSW04-CE 내부 SEER 제어기 모델과 RoboKit/펌웨어 버전. 현재 상태 API 1000 응답의 수신된 모델·버전이 있으면 현황 화면에 표시합니다.
2. 해당 버전의 TCP API 문서, 특히 경로/좌표 내비게이션, 로컬 회피 설정, 이동 장애물, 상태/실패 코드.
3. 실제 지도 SMAP, 로봇 발자국과 LiDAR 좌표/정렬 및 상태 샘플. 알고리즘은 다른 이동체의 예정 루틴을 사용하지 않습니다.
4. FR5 WebAPP/펌웨어와 대응 SDK 버전, 실제 동작/완료·safe_pose 상태 응답.

자료에 맞춰 단일 미션/상태/보고서 인터페이스를 유지하며 각 실제 장비의 제어 어댑터를 구현합니다. 로컬 검증에서는 실제 로봇 연결이나 동작 명령을 수행하지 않았습니다.

참고: 기존 구현은 docs/SOURCES_AND_API.md의 공식 TCP 문서 1.2.1과 docs/FR5_API_KO.md에 근거합니다. 현행 대상 펌웨어 호환성은 별도로 확인해야 합니다.
