# 사진형 모바일 매니퓰레이터

제공된 KakaoTalk_20261005_101012242 사진 3장을 기준으로 SBA-400EU 위의 전장 케이스와 앞쪽 FR5 배치를 재구성했습니다. 케이스는 흰색 외함, 경사진 조작 패널, 터치 화면, 비상정지·조작 버튼, 타워 표시등, 열린 측면 레일·전장 모듈·배선·케이블 덕트·통풍구를 포함합니다.

메인 3D 지도 기본 모델은 models/seer_sba400eu_description/urdf/mobile_manipulator.urdf 입니다. 맨몸 SBA-400EU는 기존 sba400eu.urdf로 유지합니다. FR5 공식 모델은 앱에서 별도 결합하며 팔 관절과 실기/SIM 자세 표시를 유지합니다.

AMR +X를 팔 장착 쪽 앞방향으로 정의합니다. 조작 패널은 -X 끝, 열린 서비스 면은 +Y입니다. 장착 위치는 AMR base 기준 X=0.310 m, Y=0, Z=0.608 m로 설정했습니다. 케이스 외형·장착 치수·질량은 사진 비율에서 추정한 값이며 실측값이 아닙니다. 실제 치수는 3D 모델 / 관절의 로봇팔 장착 위치에서 보정할 수 있습니다.

이전 중앙 장착 기본값은 앞쪽 위치로 갱신하며 사용자가 별도로 보정한 값은 유지합니다. 사진형 MoMa 복원 버튼으로 케이스와 앞쪽 장착 위치를 재적용할 수 있습니다. 보기 옵션의 사진형은 로봇을 확대해 서비스 면과 조작 패널을 함께 보여줍니다.

ROS2 모델 ZIP에도 mobile_manipulator.urdf와 관련 STL/OBJ, config/mobile_manipulator.json이 포함됩니다. FR5 메시를 이 ZIP에 복제하지 않으며 기존 공식 모델 설치 기능을 사용합니다. display.launch.py의 기본값은 맨몸 차체입니다.
