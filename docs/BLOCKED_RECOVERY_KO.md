# BLOCKED 회복 · SIM (v1.28 수정)

메인 **지도 / 제어 → 주행 장애물 대응 · SIM**의 `BLOCKED 회복 · 필요할 때만 짧게 후진 후 우회`가 기본 켜짐입니다.

장애물을 발견했다는 이유만으로 후진하거나 직전 통과 노드로 돌아가지 않습니다. 현재 위치에서 장애물 구간만 우회하고 원래 경로로 복귀하는 계획을 먼저 시도합니다.

실제로 BLOCKED에 걸렸고 현재 위치에서 안전한 우회 계획을 만들지 못할 때만 후진을 검사합니다. 현재 방향 반대쪽의 짧은 구간을 매 단계 검사하여 최대 18cm, 0.08m/s 범위에서 후진합니다. 뒤 장애물 앞 2cm 계획 여유를 남깁니다. 뒤 공간이 없거나 현재 차체가 장애물과 겹치면 강제로 움직이지 않습니다. 직전 노드 좌표는 후퇴 목표로 사용하지 않으며 180° 회전 후 노드까지 돌아가는 회복 동작은 제거했습니다.

후진한 위치에서 전방 장애물만 우회한 뒤 원래 경로 복귀를 다시 시도합니다. 회복 우회 추가 여유 1cm, 차체 충돌 반경 유지. 복귀 불가 시 기존 다른 길 탐색/불가 목적지 처리를 사용합니다. 새 장애물 접근 시 후진 중단. 명시적 정지/대기 및 자동 대기 시간 유지. 같은 위치의 회복 반복 제한.

실기 SEER 제어기 BLOCKED를 강제로 해제하거나 검사 없이 후진 TCP 명령을 보내지 않습니다. 이번 AMR 회복 변경은 SIM 엔진에 적용됩니다.
