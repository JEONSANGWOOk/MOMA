# BLOCKED 회복 · SIM

메인 **지도 / 제어 → 주행 장애물 대응 · SIM**에서 `BLOCKED 회복 · 뒤쪽 우선 / 제한 후진 우회`를 설정합니다. 기본 켜짐이며 저장됩니다. 장애물 정책은 우회/자동 판단/다른 경로 모드를 선택합니다. 명시적인 정지·대기 정책과 소프트웨어 정지, Motor OFF를 해제하지 않습니다.

1. 전방이 막히면 현재 방향의 뒤쪽 및 직전 통과 노드까지 현재 장애물을 검사합니다. 뒤가 열리고 회전 차체 공간이 확보되면 제자리 180° 회전 후 뒤쪽을 먼저 거치는 경로를 생성합니다. 회전 공간이 부족하면 안전 범위로 먼저 후진합니다.
2. 뒤쪽 통로도 막히면 뒤 장애물에 닿지 않는 짧은 구간만 후진합니다. 최대 18cm, 속도 0.08m/s이며 충돌 지점 앞 여유를 남깁니다. 이후 전방 장애물 우회 및 기존 경로 복귀를 탐색합니다. 후진 여유가 없으면 강제로 움직이지 않습니다.
3. 우회 시 추가 계획 여유를 기본 4cm에서 1cm로 줄입니다. 차체 충돌 반경·벽·금지 구역 검사는 유지합니다. 센서의 물리적 시야를 끄거나 차체 폭을 줄이는 방식이 아닙니다. 기존 경로 복귀 또는 노드 도착 시 정상 여유로 돌아옵니다.
4. 후진/회전/경로 적용 시 현재 관측 위치를 다시 검사합니다. 새 장애물이 접근하면 중단하고 재탐색합니다. 사람/AMR의 숨겨진 왕복 일정은 사용하지 않습니다. 동일 위치의 회복 반복은 제한하며 기존 다른 길 탐색·불가 목적지 처리로 이어집니다.

녹색 이동 경로 미리보기는 회복 중 실제 후진 구간을 표시합니다. 회전 중은 충돌 검사된 뒤쪽 연결 구간을 표시하며, 새 경로가 생성되면 적용 경로를 표시합니다. 대응 상태에 회복 순위와 단계가 표시됩니다.

이 기능은 프로그램 SIM 주행 엔진에 적용됩니다. 실제 SEER 제어기의 안전 BLOCKED를 강제 해제하거나 검사 없이 회전/후진 TCP 명령을 보내지 않습니다. 실기 회복은 제어기 안전 상태와 현장 LiDAR/차체 정보에 맞춘 별도 연동 검증이 필요합니다.
