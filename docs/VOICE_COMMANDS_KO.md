# 음성 / LLM 명령 · Windows 로컬 처리

워크스페이스 `음성 / LLM 명령`에서 사용합니다. 내장 마이크는 입력, 내장 스피커는 응답에 사용합니다. 상시 녹음하지 않습니다.

## 시작

1. 이 개발 노트북에는 Whisper 한국어 모델과 Qwen3 1.7B 로컬 LLM을 설치했습니다. 프로그램을 재실행하고 녹음 버튼을 누르면 됩니다. 다른 PC에서는 `음성 인식 설치/확인`, 필요 시 `로컬 LLM 설치/모델 준비`를 처음 한 번 실행합니다.
2. Windows 설정 → 개인정보 → 마이크에서 데스크톱 앱 마이크 사용을 허용하고 원하는 마이크를 기본 입력 장치로 지정합니다.
3. `녹음 시작 / 인식` 버튼을 누르고 말한 뒤 다시 눌러 인식합니다. 최대 10초 뒤 자동으로 인식합니다. 너무 짧거나 소리가 작은 녹음은 실행하지 않습니다. 녹음 파일은 인식 후 삭제합니다.
4. SIM은 기본 자동 실행입니다. 이를 끄면 인식된 명령을 미리보고 실행 버튼으로 실행합니다. 문장을 직접 입력하는 방식도 같습니다.
5. REAL은 기본 허용 꺼짐이며 자동 실행하지 않습니다. 기존 실기 연결·제어권을 갖춘 후 이번 실행에서 REAL 음성 명령 허용을 켜고, 인식된 구체적인 명령을 확인한 뒤 실행 버튼을 누릅니다. 실제 로봇 동작 검증은 아직 수행하지 않았습니다.

## 명령 예

| 명령 | 동작 |
|---|---|
| LM3로 이동해 | LM3까지 기존 주행 엔진으로 이동 |
| LM1에서 LM3로 이동해 | 현재 위치가 LM1인지 확인하고 LM3로 이동 |
| LM2, LM7, LM8 순서로 이동해 | 각 목적지를 순서대로 방문 |
| LM1, LM3 세 바퀴 돌아 | LM1→LM3→LM1, 3회 반복 |
| 현재 위치 알려줘 / 배터리 알려줘 | 상태를 화면·음성으로 안내 |
| 미션 일시정지 / 미션 재개 / 미션 취소 | 기존 미션 제어 기능 |
| 정지 / 멈춰 | LLM 해석을 기다리지 않고 인식된 정지 요청 처리 |
| 로봇팔 안전 자세로 이동해 | 등록된 safe_pose 작업 |
| 등록 작업명 + 실행해 | 등록된 팔 작업/프로그램 실행 |

`엘엠 삼`, `LM 3`, 소문자 lm3를 LM3로 정규화합니다. 출발 위치가 다르면 위치를 바꾸거나 순간이동하지 않습니다. LM1을 경유하려면 `LM1, LM3 순서로 이동해`라고 말합니다. 정지 후 정지 해제는 기존 지도/제어의 정지 해제 기능을 사용합니다.

## 로컬 처리와 적용 범위

- 명확한 기본 명령은 규칙으로 즉시 해석합니다. 복잡한 표현은 Qwen3 1.7B에 구조화된 명령으로 해석하도록 요청합니다. CPU 4개 스레드, 문맥 2048, 모델 유휴 유지 2분으로 제한합니다.
- LLM은 모터/TCP API/코드 실행을 직접 하지 않습니다. 지도에 있는 목적지, 등록된 팔 작업, 지원 명령만 검증하여 기존 미션 어댑터로 실행합니다. 일반적인 수동 속도·I/O 채널 임의 생성은 허용하지 않습니다.
- 말하지 않은 목적지 또는 불명확한 작업을 모델이 제안하면 거부합니다. 부정/수정 표현은 명확한 새 명령을 다시 요청합니다. 모델의 자연어 해석은 항상 정확하지 않으므로 미리보기 모드로 시험할 수 있습니다.
- 모델 처리 중 모드·지도·연결이 변경되면 결과 폐기. 녹음 중 변경도 폐기. 미리보기 유효시간 30초, 실행 전 노드/작업·현재 상태 다시 검사. 정지 요청은 이전 LLM 결과를 무효화합니다.
- AMR 장애물 대응과 차체 충돌 검사는 기존 엔진을 유지합니다. 팔 SIM 공유 관절/충돌 검사 및 REAL의 제어권·AMR 정지·FR5 SDK/등록 작업 확인을 유지합니다.
- 음성 정지는 인식 지연이 있으므로 물리 비상정지 장치를 대신하지 않습니다. 개발 검증에는 마이크를 녹음하지 않고 합성 한국어 WAV를 사용했습니다. 실제 발화 인식률은 마이크·소음·발음에 따라 현장에서 확인해야 합니다.

## 설치와 리소스

파일은 사용자 폴더 `.seer_amr_console/voice`에 저장합니다. 시스템 설치/자동 시작 등록을 하지 않습니다. 설치 시만 인터넷 다운로드가 필요하고, 이후 음성·LLM 처리 주소는 localhost만 허용합니다. 소스 ZIP에 모델 파일은 포함하지 않습니다.

- whisper.cpp v1.9.2 공식 Windows x64, multilingual ggml-base-q5_1 (~57MB). 모델 LFS SHA256 및 배포 ZIP digest 검증.
- Ollama v0.35.1 공식 ZIP에서 CPU 실행 파일/DLL만 부분 다운로드하고 ZIP CRC 검증. NVIDIA/AMD GPU 라이브러리를 다운로드하지 않습니다.
- Qwen3 1.7B 모델은 약 1.4GB. Ollama가 모델 SHA256을 검증합니다. Intel Arc GPU/NPU 가속을 검증한 것은 아니며 이번 기본 구성은 CPU입니다.
- 전용 서버 주소 기본 `http://127.0.0.1:12634`. 외부 Ollama를 사용할 때는 로컬 URL/모델명을 수정하고 연결 확인합니다. 프로그램이 직접 시작한 서버 프로세스만 종료 시 정리합니다.
- CLI 설치: `py -3 -X utf8 tools/install_voice_models.py --llm`.

현재 노트북(Core Ultra 5 226V, RAM 약 16GB)에서 합성 한국어 인식 약 1.75초, 소형 LLM 첫 요청(로딩 포함) 약 4.57초, 이어진 요청 약 0.42~0.51초를 측정했습니다. 문장·부하·캐시 상태에 따라 달라집니다.

공식 출처/라이선스: [whisper.cpp MIT](https://github.com/ggml-org/whisper.cpp), [Ollama MIT](https://github.com/ollama/ollama), [Qwen3 1.7B](https://ollama.com/library/qwen3:1.7b). 모델과 런타임은 공식 배포본에서 다운로드하며 프로젝트 ZIP에 재배포하지 않습니다.
