# 모바일 / 로봇팔 SIM 동기화

SIM 로봇팔은 워크스페이스, 메인 3D, 미션 Arm Action이 동일한 ArmSimulator를 사용합니다. 관절 티칭·MoveJ/MoveL·I/O·프로그램 재생은 메인 모바일 로봇팔에도 반영됩니다. 로봇팔 화면에서 선택한 2지/진공 도구도 메인 팔에 표시됩니다. 메인 모델/관절 화면에서 URDF 및 관절을 바꾸면 워크스페이스에 반영됩니다.

AMR 주행과 팔 워크스페이스 프로그램을 각각 재생하면 함께 동작합니다. 워크스페이스가 숨겨져 있어도 팔 시뮬레이션은 진행됩니다. SIM 미션 Arm Action도 같은 물리·충돌·I/O 모델을 사용하며 MoveL와 가상 I/O를 지원합니다. 이미 다른 팔 프로그램이 재생 중이면 Arm Action은 완료를 기다립니다. 한 팔에 두 개의 자세를 동시에 쓰지 않습니다. 미션 Arm Action의 일시정지/취소는 공유 팔에도 적용됩니다.

실기에서는 기존 AMR 정지·제어권·수신 상태 확인을 유지합니다. 워크스페이스 SIM 조절로 실제 FR5에 명령을 전송하지 않습니다. REAL 메인 자세는 실제 수신값을 유지하고 SIM 비교 모습만 개발 자세를 사용합니다.

기존 저장 좌표 [0,0,0.42,...] 때문에 케이스 안으로 들어가던 중앙 장착을 보정했습니다. 앞쪽 기본값은 X=.34, Y=0, Z=.626 m이고 장착판 위 스페이서를 반영했습니다. 실측값이 아니라 사진 비율 기반이며 보정 설정은 유지합니다. 사진형 MoMa 복원으로 이 기본값을 다시 적용할 수 있습니다.
