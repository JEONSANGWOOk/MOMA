# SIM 벽 충돌과 장애물 대응

`노드 / 경로` 지도 편집 모드를 **벽 만들기**로 선택하고 지도에서 시작점과 끝점을 클릭합니다. 벽은 2D와 3D에 표시되고 SIM 충돌에 적용됩니다. 가상벽도 같은 방식으로 만들며 통과할 수 없습니다. `SIM 장애물` 모드는 지도 클릭으로 원형 장애물을 추가하거나 제거합니다. 편집은 Undo/Redo를 지원하고 벽/장애물은 로컬 JSON 지도에 저장할 수 있습니다. 표시 레이어를 숨겨도 충돌은 유지됩니다.

`지도 / 제어` 오른쪽 상단의 **주행 장애물 대응 · SIM**에서 선택합니다. 기존 아래쪽 SIM 장애물 대응 항목은 이곳으로 옮겼습니다.

| 옵션 | 동작 |
|---|---|
| 장애물 피해서 가기 | 사람·AMR·정적 장애물·벽·금지구역을 모두 우회 시도. 우회 불가능하면 대기하며 다시 확인 |
| 정지하기 (수동 재개) | 앞쪽 장애물 감지 시 정지 상태를 유지. 장애물이 사라져도 자동 진행하지 않음. **장애물 정지 해제 / 주행 재개**로 다시 확인하고 진행 |
| 대기 후 기존 경로로 진행 | 기본값. 감속/정지 후 장애물이 사라지면 기존 경로로 자동 진행. 곡선 구간도 기존 곡선 유지 |
| 동적 대기 / 정적 우회 | 등록된 사람·AMR 동적 장애물은 지나갈 때까지 대기. 벽·금지구역·정적 원형 장애물은 우회 시도 |

우회는 충돌 여유를 포함한 격자 A*로 계산합니다. 통과 노드가 막히면 현재 이동 명령의 최종 목적지를 유지하며 해당 노드를 우회할 수 있습니다. 최종 목적지가 막혔거나 우회 경로를 찾지 못하면 대기하고 다시 확인합니다. 정지 유지 상태는 옵션을 바꾸는 것만으로 해제하지 않고 재개 버튼을 사용해야 합니다.

v1.4부터 우회는 장애물 뒤의 가까운 안전 지점에서 **기존 직선/곡선 경로로 복귀**하는 계획을 우선합니다. 복귀 이후의 기존 경로를 보존하여 목적지까지 옆으로 비스듬히 가는 경로를 줄였습니다. 복귀 지점과 우회 구간의 차체 충돌을 확인합니다. 후보 검색은 약 0.12m 간격이며 엄밀한 최단 복귀점 보장은 아닙니다. 가까운 복귀가 불가능하면 목적지 우회를 시도하고, 그마저 불가능하면 대기합니다. 이후 경로의 다른 장애물은 접근 시 다시 처리합니다. [기존 라인 복귀 화면](../artifacts/obstacle_early_rejoin.png).

## 움직이는 사람 / AMR

1. 같은 메인 패널의 **사람 추가** 또는 **AMR 추가**를 누릅니다.
2. 시작·끝 X/Y(m), 속도(0.01~2m/s), 충돌 반경(0.1~2m), 끝점 대기(0~60초)를 설정합니다. **지도에서 시작·끝 선택**을 누르면 노드/경로 지도로 이동하며 두 점을 클릭해 입력할 수 있습니다.
3. **저장 / 배치**를 누르면 시작점에서 끝점까지 왕복합니다. 사람 기본 반경 0.3m/속도 0.6m/s, AMR 기본 반경 0.61m/속도 0.35m/s입니다. 시작점을 제어 AMR이나 벽과 겹치게 배치할 수 없습니다.
4. **동적 장애물 일시정지**로 전체를 멈춥니다. **관리**에서 개별 경로·속도를 수정하거나 삭제합니다. 수정 시 해당 장애물을 시작점에 다시 배치합니다.

사람은 주황색 사람 형태, 다른 AMR은 보라색 차체로 표시합니다. 현재 위치·ID·걷는 중/주행 중/끝점 대기/통행 대기 상태와 왕복 구간을 2D/3D에서 확인할 수 있습니다. SIM LiDAR도 장애물의 현재 위치를 반영합니다. 움직이는 장애물 자체도 벽·금지구역·다른 장애물·제어 AMR와 충돌할 이동을 중단하고 **통행 대기**합니다. 서로 마주 선 좁은 길에서 교착되면 경로를 수정해야 하며, 사람이나 다른 AMR에 별도 우회 AI는 적용하지 않았습니다.

동적/정적 분류는 SIM에 등록한 종류에 따릅니다. 일시정지한 사람/AMR도 동적 종류로 유지되어 자동 정책에서 대기합니다. 실제 LiDAR 점에서 사람을 인식하거나 추적하는 기능은 아닙니다.

배치와 왕복 경로는 **로컬 JSON 지도**에 저장됩니다. 다음 로드 시 장애물은 저장된 시작점에서 다시 출발하며 순간 위치/이동 진행률은 저장하지 않습니다. SMAP 업로드로 실기 장애물을 생성하지 않습니다. SIM 전원이 꺼지면 장애물도 움직이지 않습니다. 미션 자체의 제한 시간이 지나면 기존 미션 실패/취소 규칙이 적용됩니다.

실제 계산된 이동 경로를 기존 초록색 경로로 표시하므로 2D와 3D에서 돌아가는 방향을 볼 수 있습니다. 목적지별 미션 Action은 유지하며, 우회용 중간 좌표를 별도의 정지 목적지로 추가하지 않습니다. 수동 버튼·키보드·DualSense 조종은 장애물 앞에서 정지하며 자동 우회하지 않습니다.

벽 선분, 가상벽, 원형 장애물과 금지구역을 충돌 대상으로 사용하고 이동 구간도 검사합니다. 기본 SEER AMB-CSW04-CE는 958.2 × 631.4 mm 차체의 외접 원과 벽 두께 여유를 포함해 약 0.60 m의 반경을 적용합니다. 로봇 모델에 지정된 반경이 더 크면 그 값을 사용합니다. 이 원형 모델은 회전 시에도 차체가 겹치지 않도록 보수적으로 계산하므로 실제 차체가 통과할 수 있는 일부 좁은 길에서도 대기할 수 있습니다. 외부 시각화 모델은 주행 모델의 길이/폭/반경도 맞춰 설정하세요.

대응 정책은 사용자 설정에 저장되고 다음 실행에서 복원됩니다. 이 옵션은 **SIM 전용**이며 실제 SEER 컨트롤러 설정을 변경하지 않습니다. 우회는 자유 공간을 사용하므로 지도 경로선에서 벗어날 수 있고, 기존 경로의 일방통행·차선 규칙까지 적용하는 교통 계획은 아닙니다. 벽과 금지구역은 우회 중에도 통과하지 않습니다. 격자 해상도와 검색량은 제한되어 있어 경로가 있어도 좁거나 복잡한 공간에서는 찾지 못할 수 있으며, 그 경우 대기합니다. 센서 점군 자체는 충돌 물체로 변환하지 않습니다.

검증 예시: [벽을 피하는 초록색 이동 경로](../artifacts/sim_wall_avoidance.png).

## 다중 포인트 이동

**동적 장애물 다중 포인트 이동**: 메인의 `AMR 추가`에서 기존 노드를 여러 개 선택합니다. AMR은 중간 노드와 곡선을 포함한 실제 연결 경로를 따라갑니다. `사람 추가`에서는 좌표 포인트를 여러 개 등록합니다. 포인트 추가·삭제·순서 변경, 왕복·순환, 속도·등록 포인트 대기 시간을 설정할 수 있습니다. 왕복의 돌아오는 길과 순환의 마지막→첫 노드 연결도 검증합니다. 연결 경로가 없으면 저장하지 않습니다.

등록한 포인트에서만 설정한 시간 동안 대기하며 경유 노드와 곡선 샘플에서는 멈추지 않습니다. 벽·로봇·다른 장애물과 충돌할 경우 통행을 기다립니다. 사람은 좌표 사이를 직선으로 이동합니다. 기존 두 점 설정도 읽을 수 있으나, 이전 AMR 좌표 경로를 수정할 때는 기존 노드를 새로 선택해야 합니다.

지도 파일에 포인트 목록, 노드 목록, 이동 방식과 속도가 저장됩니다. 실행 중 위치 대신 첫 포인트를 초기 위치로 저장합니다. 경로가 변경되면 장애물을 다시 배치하세요.

## 다른 경로 탐색과 패스

**정적 장애물의 다른 경로 탐색 / 목적지 패스**: 메인의 `주행 장애물 대응 · SIM`에서 `정적 대기 → 다른 경로 / 불가 목적지 패스`를 선택합니다. 기본 5초 대기 후 지도에 연결된 다른 경로를 찾으며, 다시 막히면 재탐색합니다. 탐색 실패가 기본 3회 반복되면 목적지와 해당 위치의 팔·I/O 작업을 생략하고 다음 목적지로 이동합니다. 2D·3D 빨간 마킹과 별도 이력에 이유를 남깁니다.

동적 장애물은 기다리고, 정적 장애물만 대기 후 다른 연결 경로를 탐색합니다. 단일 목적지 이동은 패스 후 멈추고, 미션에 다음 Path Nav가 있을 때 다음 목적지로 이동합니다. 대기 0~60초, 탐색 실패 1~10회를 설정할 수 있습니다. 이 기능은 SIM 전용입니다.


## 자동 판단 / 장애물별 시나리오

**자동 장애물 판단과 대응 시나리오**: 메인의 `주행 장애물 대응 · SIM`에서 `자동 판단 / 장애물별 시나리오`를 선택하세요. `자동 판단 / 장애물별 시나리오 설정`에서 동적·정적·판단 중 각각의 행동을 지정하고, 개별 장애물에 별도 시나리오를 지정할 수 있습니다. 기본은 동적·판단 중 대기, 정적 5초 대기 후 다른 연결 경로 탐색·불가 목적지 패스입니다.

판단 알고리즘은 종류 이름이나 dynamic 플래그로 동작을 정하지 않고, 장애물의 월드 좌표 변화를 시간에 따라 추적합니다. 최근 약 0.8초 이동량에서 속도를 추정하고, 0.3초 이상 관측·2.5cm 이상 이동·설정 속도 이상일 때 동적으로 판단합니다. 기본 속도 기준은 0.08m/s입니다. 움직임 증거가 사라진 뒤 기본 2초 이상 정지 상태가 유지되면 정적으로 판단합니다. 짧은 정지나 작은 위치 흔들림으로 판단이 즉시 뒤집히지 않도록 유지 시간을 둡니다. 벽·가상벽·금지구역은 지도상 고정 요소로 처리합니다.

현재는 SIM 객체의 월드 좌표 관측을 사용합니다. 실제 LiDAR 점군 군집화·좌표 보정·다중 대상 추적과 실기 AMR 주행 제어에는 적용되지 않습니다.

선택 가능한 행동:
- 해제될 때까지 대기
- 정지 / 수동 재개
- 주변 우회 후 기존 경로 복귀
- 다른 연결 경로 탐색 / 불가 목적지 패스
- 설정 시간 대기 후 주변 우회
- 설정 시간 대기 후 다른 연결 경로 탐색 / 패스

사람·AMR도 오래 정지하면 정적으로 분류되며 선택한 정적 시나리오가 적용됩니다. 기본 시나리오는 전체 장애물에 적용하고, 설정 창에서 특정 장애물을 선택하여 개별 적용 체크를 켜면 해당 장애물에만 별도 대응을 지정합니다. 체크를 해제하고 저장하면 기본 대응으로 복귀합니다. 기본 설정은 프로그램 설정에, 개별 설정은 지도 파일에 저장됩니다.

자동 모드의 다른 경로 탐색은 현재 점유된 동적 장애물 경로도 제외합니다. 재탐색이 실패하면 메인의 다른 길 대기 시간 후 다시 시도하고, 설정된 실패 횟수에 도달하면 목적지를 패스합니다. 주변 우회 경로가 없으면 안전하게 대기하며 자동으로 목적지를 패스하지 않습니다. 초기 판단 중 대기에는 시간 제한이 없습니다. 전역 대기·속도·정적 유지 시간 기준은 설정 창에서 변경할 수 있습니다.

기존 저장 설정의 수동 정책은 유지됩니다. 새 설정에서는 자동 판단 모드가 기본입니다.


## 신규 장애물 추적

**신규 장애물 마킹 / 지속 추적**: 지도에 등록된 고정 장애물은 신규 추적에서 제외합니다. 새로 관측된 장애물에는 `TRK001` 형식의 추적 ID를 부여하고, 2D·3D 지도에서 위치·관측 궤적·동적/정적 판단을 갱신합니다. 동적·정적 판단이 바뀌어도 ID를 유지합니다. 메인의 `신규 장애물 추적 목록`에서 좌표·속도·관측 상태를 확인할 수 있습니다.

신규 판단은 지도 고정 장애물과 구분됩니다. 기존 지도에서 불러온 고정 장애물과 `고정 장애물 추가`로 배치한 항목은 신규 마킹에서 제외합니다. `신규 감지 장애물 배치 · SIM`을 누른 뒤 지도를 클릭하면 지도 미등록 장애물을 시험할 수 있습니다. 사람·AMR 동적 장애물도 신규 추적 대상입니다. 신규 장애물이 정지하여 정적으로 판단되더라도 자동으로 지도 고정 장애물로 등록하지 않습니다.

SIM 관측은 로봇 주변 8m 이내와 벽/다른 장애물에 가려지지 않은 대상에 한정합니다. 이는 SIM 객체 위치에 가시성 검사를 적용한 관측이며 실제 LiDAR 점군 처리 결과가 아닙니다. 종류 플래그는 추적 ID에 영향을 주지 않으며 위치 변화로 동적·정적 판단을 갱신합니다.

동일 객체 또는 동일 원본 ID를 먼저 연결하고, 다른 관측 자료로 교체되면 위치·크기가 가까운 대상으로 연결합니다. 동시 관측한 여러 장애물에는 서로 다른 ID를 부여합니다. 객체가 교차하거나 가까이 겹치면 거리 기반 연결이 잘못될 수 있습니다.

마킹 색상은 동적 파랑, 정적 빨강, 판단 중 주황, 미관측 회색입니다. 1초 동안 관측하지 못하면 마지막 위치에서 미관측으로 표시하고, 30초 후 제거합니다. 3초 이내의 근접 재관측이나 동일 객체 재관측은 기존 ID로 연결합니다. 미관측 후 재발견하면 궤적 선을 새로 시작해 관측하지 않은 이동을 임의 직선으로 그리지 않습니다. 위치가 실제로 관측된 때만 궤적을 추가하며 최근 최대 120개 위치를 보관합니다.

메인의 `신규 장애물 마킹 / 궤적 표시`로 마킹을 켜거나 끌 수 있고, 장애물 레이어가 꺼지면 마킹도 숨깁니다. `신규 장애물 추적 목록`은 계속 갱신되며 현재/마지막 좌표와 속도, 미관측 시간을 보여줍니다. 미관측 마킹 자체는 주행 장애물로 추가하지 않습니다.

추적 ID·궤적·판단 이력은 해당 SIM 실행의 정보입니다. 지도 저장에는 `map_fixed` 구분과 시험 장애물 설정을 저장하며 실행 이력은 넣지 않습니다. 지도 재로딩과 SIM 재시작 시 추적 ID를 새로 부여합니다. 실제 센서 기반 감지와 실기 AMR 주행에는 적용하지 않았습니다.


## 상호 정지 해소

**동적 장애물 상호 정지 해소 수정**: 메인의 `상호 정지 자동 해소 적용`으로 자동 판단의 기본 대응을 선택합니다. 정지한 사람·AMR을 정적으로 재분류한 뒤 설정 시간만큼 기다리고, 주변 우회 → 다른 연결 경로 탐색 → 모두 불가할 때 목적지 패스 순서로 진행합니다. 기존 `다른 경로 탐색`과 `동적 대기 / 정적 우회`도 등록 종류 대신 관측한 움직임·정지 시간을 반영합니다.

자동 기본 정적 시나리오는 `대기 → 주변 우회 → 다른 경로 / 패스`입니다. 기존 설정에 저장된 시나리오는 유지되므로 메인의 적용 버튼으로 새 기본값을 선택하세요. 개별 장애물에 대기를 지정한 경우 해당 지정이 우선합니다. 수동 정지 상태는 버튼을 눌러도 자동 해제하지 않습니다.

다른 경로 탐색 모드는 주변 자유 공간 우회를 하지 않습니다. 정지한 동적 객체는 정적으로 재분류하고 현재 점유 중인 경로를 제외하여 다른 연결 경로를 찾습니다. 연결된 다른 경로가 없으면 재시도 후 패스합니다. 주변 우회까지 원하면 자동 해소 시나리오를 사용하세요.

근접 정지 상태에서 기존 추가 4cm 계획 버퍼 때문에 출발점이 막힌 것으로 판정되면 실제 충돌 반경을 그대로 둔 채 추가 버퍼 없이 경로를 재탐색합니다. 출발점 자체가 실제 충돌 중이면 이 처리를 하지 않습니다. 실제 이동 시 충돌 검사는 계속 적용됩니다. 실제 로봇 제어기에 대한 상호 정지 해소 기능은 변경하지 않았습니다.


## 경로 중간에서 출발 노드 복귀

**LM2→LM7→LM8 복귀 경로 탐색 수정**: 경로 중간에서 장애물 가까이에 멈추었을 때 추가 계획 여유 거리 때문에 출발 노드 복귀 구간까지 탈락하는 문제를 수정했습니다. 실제 충돌 반경을 유지한 구간 검사로 안전한 기존 경로 복귀를 허용합니다. 양방향 연결에서만 되돌아가며, 일방통행 경로는 임의 역주행하지 않습니다.

전체 대체 연결 경로는 기존 추가 여유 거리를 유지합니다. 현재 위치가 추가 여유 거리 안이지만 실제 충돌은 없을 때에만 출발/도착 노드까지의 기존 경로 구간을 실제 반경으로 검사합니다. 새 대각선 연결이나 순간 위치 변경을 만들지 않습니다.


## 주행 중 고정 장애물 삭제와 동적 장애물끼리 만남

**주행 중 고정 장애물 삭제 / 동적 장애물 상호 만남 처리**: 메인의 `고정 장애물 / 벽 관리·삭제`에서 고정 장애물·신규 정지 장애물·벽·가상벽을 선택해 삭제합니다. 주행은 취소하지 않습니다. 사람·AMR 동적 장애물끼리 막히면 기본 2초 후 반대 방향으로 이동하고, 추가/수정 창에서 대기 시간과 계속 대기 옵션을 선택할 수 있습니다. AMR은 기존 경로와 반대 방향 통행 가능 여부를 확인합니다.

관리 창은 주행 중에도 열 수 있으며 목록의 좌표로 항목을 확인하고 여러 항목을 선택해 삭제할 수 있습니다. 동적 사람·AMR은 기존 관리 버튼에서 삭제합니다. 지도 저장을 해야 고정 장애물·벽 삭제가 다음 실행의 지도에도 남습니다. 주행 로봇이 장애물 정지로 수동 정지 유지 상태에 있으면 삭제 후에도 수동 재개가 필요합니다. 일반 충돌 대기는 다음 시뮬레이션 갱신에서 다시 평가합니다.

동적 장애물의 추가/수정 창에서 `다른 사람·AMR와 막힘`을 `대기 후 반대 방향` 또는 `계속 대기`로 선택합니다. 방향 전환 대기는 0.1~60초이며 기본 2초입니다. 반대 방향으로 다음 경로 포인트를 따라가고 등록 포인트 대기 설정을 유지합니다. 수동 일시정지된 장애물은 자동으로 재개하지 않습니다.

벽·고정 장애물·주행 로봇 본체 때문에 막힌 경우는 충돌 방지 대기를 유지합니다. AMR은 현재 구간에 실제 반대 방향 연결이 있으며 같은 이동 기하를 따라 안전하게 돌아갈 수 있을 때만 반전합니다. 단방향 구간이나 통행 공간이 없는 배치에서는 무조건 계속 움직이게 만들지 않고 안전하게 기다립니다. 순간 위치 이동이나 충돌을 허용하지 않습니다.


## 루프 미션 시간 제한과 반복 우회

**우회 중 루프 미션 자동 취소 수정**: 자동 판단·다른 경로 탐색의 SIM Path Nav는 단계 시작부터의 전체 시간 대신 실제 위치 이동이 없는 시간을 기준으로 제한을 확인합니다. 경로를 바꾸며 계속 이동하는 경우 미션을 유지합니다. 오랫동안 실제 이동이 없으면 해당 목적지만 패스하고 다음 목적지·반복으로 이어갑니다. 도착 후 설정한 대기 시간도 우회 누적 시간 때문에 실패하지 않습니다.

적용 범위는 SIM의 `자동 판단 / 장애물별 시나리오`와 `정적 대기 → 다른 경로 / 불가 목적지 패스`입니다. 0.1m 이상의 실제 위치 변화가 있으면 주행 무진행 타이머를 갱신합니다. 경로 재탐색 메시지만 반복되고 움직이지 않는 경우에는 갱신하지 않습니다.

설정된 Path Nav 시간 제한을 무진행 기준으로 사용합니다. 자동 대응 대기·재탐색에 필요한 최소 시간은 기존과 같이 확보합니다. 무진행 제한을 넘긴 목적지는 지도에 마킹하고, 해당 목적지의 팔/I/O 등 후속 작업을 생략한 다음 다음 Path Nav로 진행합니다. 무한 반복에서는 다음 반복에서도 목적지에 다시 도전합니다.

미션 상태 표시에는 전체 단계 경과 시간과 `무진행 Ns`를 함께 표시합니다. 안전 정지·전원/연결 이상 등은 자동 패스로 숨기지 않습니다. 실기 AMR, 다른 SIM 정책, 팔/I/O/장비 작업의 기존 시간 제한은 변경하지 않았습니다.


## 지도 확대 / 경로 탐색 보강 / 마킹 수명

**지도 영역 확대 / 연결 경로 탐색 보강 / 패스 마킹 정리**: 하단의 긴 지도 정보·조작 안내를 한 줄 요약과 `상세`로 줄였습니다. `지도 크게`로 제어 패널을 접어 지도 영역을 넓힐 수 있으며 정지 버튼은 남습니다. 탐색은 현재 위치의 모든 연결 경로 복귀 지점을 검사하고, 뒤로 복귀·먼 우회·이전 우회 후 재복귀를 검토합니다. 새 미션은 이전 패스 마킹을 초기화하며, 반복 중 마킹은 실제 노드 방문 시 지웁니다.

지도 하단은 지도 이름·노드/경로 수·배율·LiDAR 점 수 요약입니다. 정합 점수와 조작 안내는 `상세`에서 확인합니다. 지도 위의 `지도 크게`를 누르면 오른쪽 제어 패널을 접고 지도 폭을 확대합니다. `제어 패널 보기`로 복원합니다. 확대 모드에도 정지 버튼과 Esc 조작을 유지합니다.

메인의 `전체 경로 확인 / 연결 경로 우선 탐색`은 기본 켜짐입니다. SIM 자동 판단·다른 경로 탐색에서 현재 목적지까지 남은 모든 구간을 약 1초마다 확인합니다. 이후 구간에서 동적·정적 장애물이 발견되면 다른 연결 경로를 미리 검토하고 가능하면 전환합니다. 자동 시나리오에서 명시적으로 지정한 계속 대기·수동 정지는 유지합니다. 옵션을 끄면 기존 근접 감지 시나리오 순서로 동작합니다.

그래프 탐색에는 거리 상한을 두지 않고, 현재 위치와 일치하는 모든 방향별 경로에서 안전한 복귀 후보를 계산합니다. 지나온 노드와 다음 노드만 고정해서 보지 않습니다. 역방향 연결이 있는 경로에서는 되돌아가 더 먼 길을 선택할 수 있으며 일방통행 역주행은 허용하지 않습니다. 전체 노드 연결을 검색하되 막힌 연결은 제외합니다. 추가 안전 여유 거리 때문에 모든 후보가 실패하면 실제 로봇 반경을 그대로 사용하여 다시 검사합니다. 실제 충돌 공간을 지나가거나 순간 위치 이동을 하지 않습니다.

이전 주변 우회로 인해 현재 위치가 지도 연결 경로 밖에 있으면 목적지까지 실제 연결이 가능한 노드들의 복귀 경로를 충돌 검사하여 찾습니다. 먼저 제한된 격자 검색을 시도하고 실패하면 검색 범위를 늘려 재시도합니다. 한 후보 실패를 곧바로 목적지 불가로 처리하지 않습니다. SIM 객체 상태를 사용하며 실제 LiDAR 기반 전역 길찾기는 변경하지 않습니다.

새 미션을 처음부터 실행하면 이전 패스/도달 불가 지도 마킹을 모두 지웁니다. 같은 미션의 다음 반복에서는 실패 마킹을 유지하고 해당 노드에 실제로 도착하거나 경유하면 그 노드 마킹을 해제합니다. 방문하지 못한 노드 마킹은 계속 남습니다. 패스 기록 자체는 미션 이력으로 유지하며 화면에는 `패스 이력 N건`으로 구분합니다.
