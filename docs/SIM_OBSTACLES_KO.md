# SIM 벽 충돌과 장애물 대응

`노드 / 경로` 지도 편집 모드를 **벽 만들기**로 선택하고 지도에서 시작점과 끝점을 클릭합니다. 벽은 2D와 3D에 표시되고 SIM 충돌에 적용됩니다. 가상벽도 같은 방식으로 만들며 통과할 수 없습니다. `SIM 장애물` 모드는 지도 클릭으로 원형 장애물을 추가하거나 제거합니다. 편집은 Undo/Redo를 지원하고 벽/장애물은 로컬 JSON 지도에 저장할 수 있습니다. 표시 레이어를 숨겨도 충돌은 유지됩니다.

`지도 / 제어` 오른쪽 상단의 **주행 장애물 대응 · SIM**에서 선택합니다. 기존 아래쪽 SIM 장애물 대응 항목은 이곳으로 옮겼습니다.

| 옵션 | 동작 |
|---|---|
| 장애물 피해서 가기 | 사람·AMR·정적 장애물·벽·금지구역을 모두 우회 시도. 우회 불가능하면 대기하며 다시 확인 |
| 정지하기 (수동 재개) | 앞쪽 장애물 감지 시 정지 상태를 유지. 장애물이 사라져도 자동 진행하지 않음. **장애물 정지 해제 / 주행 재개**로 다시 확인하고 진행 |
| 대기 후 기존 경로로 진행 | 기본값. 감속/정지 후 장애물이 사라지면 기존 경로로 자동 진행. 곡선 구간도 기존 곡선 유지 |
| 동적 대기 / 정적 우회 | 등록된 사람·AMR 동적 장애물은 지나갈 때까지 대기. 벽·금지구역·정적 원형 장애물은 우회 시도 |

우회는 충돌 여유를 포함한 격자 A*로 계산합니다. 통과 노드가 막히면 현재 이동 명령의 최종 목적지를 유지하며 해당 노드를 우회할 수 있습니다. 최종 목적지가 막혔거나 우회 경로를 찾지 못하면 대기하고 다시 확인합니다. 정지 유지 상태는 옵션을 바꾸는 것만으로 해제하지 않고 재개 버튼을 사용해야 합니다.

v1.4부터 우회는 장애물 뒤의 가까운 안전 지점에서 **기존 직선/곡선 경로로 복귀**하는 계획을 우선합니다. 복귀 이후의 기존 경로를 보존하여 목적지까지 옆으로 비스듬히 가는 경로를 줄였습니다. 복귀 지점과 우회 구간의 차체 충돌을 확인합니다. 후보 검색은 약 0.12m 간격이며 엄밀한 최단 복귀점 보장은 아닙니다. 가까운 복귀가 불가능하면 목적지 우회를 시도하고, 그마저 불가능하면 대기합니다. 이후 경로의 다른 장애물은 접근 시 다시 처리합니다. [기존 라인 복귀 화면](../artifacts/obstacle_early_rejoin.png).

## 움직이는 사람 / AMR

1. 같은 메인 패널의 **사람 추가** 또는 **AMR 추가**를 누릅니다.
2. 시작·끝 X/Y(m), 속도(0.01~2m/s), 충돌 반경(0.1~2m), 끝점 대기(0~60초)를 설정합니다. **지도에서 시작·끝 선택**을 누르면 노드/경로 지도로 이동하며 두 점을 클릭해 입력할 수 있습니다.
3. **저장 / 배치**를 누르면 시작점에서 끝점까지 왕복합니다. 사람 기본 반경 0.3m/속도 0.6m/s, AMR 기본 반경 0.61m/속도 0.35m/s입니다. 시작점을 제어 AMR이나 벽과 겹치게 배치할 수 없습니다.
4. **동적 장애물 일시정지**로 전체를 멈춥니다. **관리**에서 개별 경로·속도를 수정하거나 삭제합니다. 수정 시 해당 장애물을 시작점에 다시 배치합니다.

사람은 주황색 사람 형태, 다른 AMR은 보라색 차체로 표시합니다. 현재 위치·ID·걷는 중/주행 중/끝점 대기/통행 대기 상태와 왕복 구간을 2D/3D에서 확인할 수 있습니다. SIM LiDAR도 장애물의 현재 위치를 반영합니다. 움직이는 장애물 자체도 벽·금지구역·다른 장애물·제어 AMR와 충돌할 이동을 중단하고 **통행 대기**합니다. 서로 마주 선 좁은 길에서 교착되면 경로를 수정해야 하며, 사람이나 다른 AMR에 별도 우회 AI는 적용하지 않았습니다.

동적/정적 분류는 SIM에 등록한 종류에 따릅니다. 일시정지한 사람/AMR도 동적 종류로 유지되어 자동 정책에서 대기합니다. 실제 LiDAR 점에서 사람을 인식하거나 추적하는 기능은 아닙니다.

배치와 왕복 경로는 **로컬 JSON 지도**에 저장됩니다. 다음 로드 시 장애물은 저장된 시작점에서 다시 출발하며 순간 위치/이동 진행률은 저장하지 않습니다. SMAP 업로드로 실기 장애물을 생성하지 않습니다. SIM 전원이 꺼지면 장애물도 움직이지 않습니다. 미션 자체의 제한 시간이 지나면 기존 미션 실패/취소 규칙이 적용됩니다.

실제 계산된 이동 경로를 기존 초록색 경로로 표시하므로 2D와 3D에서 돌아가는 방향을 볼 수 있습니다. 목적지별 미션 Action은 유지하며, 우회용 중간 좌표를 별도의 정지 목적지로 추가하지 않습니다. 수동 버튼·키보드·DualSense 조종은 장애물 앞에서 정지하며 자동 우회하지 않습니다.

벽 선분, 가상벽, 원형 장애물과 금지구역을 충돌 대상으로 사용하고 이동 구간도 검사합니다. 기본 SEER AMB-CSW04-CE는 958.2 × 631.4 mm 차체의 외접 원과 벽 두께 여유를 포함해 약 0.60 m의 반경을 적용합니다. 로봇 모델에 지정된 반경이 더 크면 그 값을 사용합니다. 이 원형 모델은 회전 시에도 차체가 겹치지 않도록 보수적으로 계산하므로 실제 차체가 통과할 수 있는 일부 좁은 길에서도 대기할 수 있습니다. 외부 시각화 모델은 주행 모델의 길이/폭/반경도 맞춰 설정하세요.

대응 정책은 사용자 설정에 저장되고 다음 실행에서 복원됩니다. 이 옵션은 **SIM 전용**이며 실제 SEER 컨트롤러 설정을 변경하지 않습니다. 우회는 자유 공간을 사용하므로 지도 경로선에서 벗어날 수 있고, 기존 경로의 일방통행·차선 규칙까지 적용하는 교통 계획은 아닙니다. 벽과 금지구역은 우회 중에도 통과하지 않습니다. 격자 해상도와 검색량은 제한되어 있어 경로가 있어도 좁거나 복잡한 공간에서는 찾지 못할 수 있으며, 그 경우 대기합니다. 센서 점군 자체는 충돌 물체로 변환하지 않습니다.
