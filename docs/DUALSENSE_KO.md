# DualSense CFI-ZCT1G로 AMR 조종

Windows 노트북에서 USB 또는 Bluetooth로 연결하고 Windows 게임 컨트롤러로 인식되면 사용할 수 있습니다. 추가 Python 패키지는 필요하지 않습니다. USB는 충전 전용이 아닌 데이터 케이블을 사용하세요. Bluetooth 페어링은 PS + Create 버튼을 길게 눌러 표시등이 깜박일 때 Windows Bluetooth 설정에서 Wireless Controller를 선택합니다. [Sony 연결 안내](https://www.playstation.com/en-us/support/hardware/pair-dualsense-controller-bluetooth/)

1. 프로그램을 재실행하고 시뮬레이션 또는 실기 · 제어 모드로 연결합니다.
2. `지도 / 제어` 우측을 아래로 스크롤해 `수동 조작`을 엽니다.
3. `컨트롤러 검색 / 설정`에서 장치를 선택하고 `선택한 컨트롤러 연결`을 누릅니다. 시작 시 단일 Sony DualSense가 인식되면 자동 선택되지만 조종은 꺼져 있습니다.
4. 입력 표시를 보며 왼쪽 스틱 X/Y와 L1, ○의 번호를 확인한 후 적용/저장합니다. 기본값은 X/Y, L1=5번, ○=3번입니다. 드라이버/가상 컨트롤러에 따라 다르면 설정에서 바꿉니다. 축 반전과 데드존도 조정할 수 있습니다.
5. `수동 조작 활성화`와 `DualSense 조이스틱 사용`을 켭니다. 스틱을 중앙에 놓고 L1을 놓았다가 다시 누릅니다.

- 왼쪽 스틱 위/아래: 전진/후진. 좌/우: 회전. 동시에 기울이면 전후진과 회전을 함께 수행합니다. AMR의 횡이동은 사용하지 않습니다.
- L1: 누르고 있는 동안만 조종. 스틱 중앙 또는 L1 해제: 수동 주행 중단.
- ○: 기존 소프트웨어 정지 동작 실행, 조이스틱 사용 해제. 조종을 재개하려면 기존 정지 해제·모터 ON 조건을 확인하고 조이스틱 사용을 다시 켭니다.
- 속도는 기존 m/s 및 deg/s 설정을 최대값으로 사용합니다. 허용 범위는 0.01~0.30 m/s, 회전 0 초과~0.6 rad/s입니다. 기본 데드존은 15%입니다.

2D와 3D 모두 같은 조종 기능을 사용합니다. 지도 / 제어 화면과 앱 포커스가 필요하며, 다른 창이나 작업 화면으로 이동하면 조종을 중단합니다. 설정 창에서는 입력 확인만 가능하며 주행하지 않습니다. 키보드/마우스 수동 조작이나 개별 목적지 이동을 시작하면 조이스틱 사용을 해제합니다. 미션 수행 중에는 스틱 주행을 차단합니다. 팔 작업 완료 및 안전 자세가 필요합니다.

컨트롤러 연결 해제, 오래된 입력, 상태 데이터 지연, 제어권 해제 시 주행을 중단합니다. 실기 속도 명령에 250 ms의 내부 유효기간을 적용하고, 입력 갱신이 멈추면 기존 TCP 송신 스레드에서 정지 명령을 요청합니다. 통신 오류 또는 컨트롤러의 명령 거절 시 조이스틱 사용이 해제됩니다. 실제 정지 응답 시간은 로봇 제어기와 통신 상태에 영향을 받습니다.

다시 연결한 뒤 장치를 재선택하고 조종을 활성화해야 하며, 스틱 중앙 + L1 해제로 준비 상태를 확인해야 합니다. 소프트웨어 정지는 하드웨어 비상정지 버튼과 별개입니다.

장치가 보이지 않으면 `Win + R → joy.cpl`에서 Windows가 인식하는지 확인하고 연결 후 설정 창을 다시 여세요. Steam/가상 컨트롤러가 입력을 변환하고 있으면 장치 선택과 버튼 번호를 다시 확인합니다. 현재 입력은 Windows WinMM 조이스틱 인터페이스를 사용합니다. 진동·적응형 트리거·로봇팔 관절 조종은 이 기능에 포함하지 않습니다.
