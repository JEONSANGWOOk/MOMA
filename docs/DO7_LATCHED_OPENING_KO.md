# DO7 ON 유지 중 후크/롤러 고정 추종

2026-11-09 사용자 요청: ON 동안 후크가 빠지지 않고 0~60도 열림, 다음 ON에서 롤러가 60~120도 열림. OFF에서는 자세 변경을 따라가지 않고 각도 유지. 세 번째 닫기 ON/OFF의 부드러운 닫기 완료는 유지합니다.

## 실제 녹화 분석

최근 정상 종료 전체 녹화 latest.json에는 세 DO7 ON 구간이 확인됩니다. 첫 구간은 후크 Tool 44표본, 두 번째는 롤러 Tool 102표본, 세 번째는 닫기 93표본입니다. DO7의 실제 수신은 정상입니다. 종전 코드는 ON에도 CAD 접촉을 재획득하거나 자세/시간 간격 때문에 해제했습니다. Tool 정보가 미수신인 OFF 구간에는 단계 전환을 놓칠 수도 있었습니다.

새 방식은 세 ON/OFF 펄스로 단계 전환하며 Tool 이름이 순간 미수신돼도 OFF와 다음 ON을 처리합니다. 첫 ON의 실제 자세를 기준으로 회전량을 누적하며, ON 중에는 거리 접촉을 재판정해 후크/롤러를 떼지 않습니다. 잠깐의 수신 누락은 각도를 유지하고 기준을 보존합니다. 역방향 흔들림은 진행량에 반영하되 문을 역으로 당기거나 같은 흔들림을 반복 더하지 않습니다. DO7만 ON이고 자세가 정지했으면 문도 움직이지 않습니다.

후크는 0~60도, 롤러는 60~120도로 표시합니다. 현재 실기 시나리오의 두 번째 ON은 SetTool/접근 MoveL 이전부터 켜져 있어, 순수 Rotate100도 외에도 접근 자세 변화가 포함됩니다. 실제 녹화의 누적 회전은 후크 **58.94488도**, 롤러 구간 **131.18871도**였습니다. 이 측정량을 각 구간의 60도 개방에 대응시킨 표시 배율을 저장했습니다. 이는 물리 문 각도 측정이나 로봇 회전 명령 변경이 아닙니다.

ON 구간을 단순히 실제 회전 1도=문 1도로 적용하면 롤러 접근 자세까지 들어가 목표 각도에 일찍 도달할 수 있습니다. 새 배율은 해당 전체 ON 구간에 맞춘 것입니다. 시나리오의 회전량이나 ON 위치를 바꾸면 새 전체 녹화로 기준을 다시 맞춰야 합니다.

OFF 시 남은 표시 오차가 2도 이내이면 60/120도 끝점으로 정리합니다. 그보다 큰 미완료 움직임을 무조건 완료로 만들지는 않습니다. 닫기 OFF의 자동 0도 애니메이션은 사용자 요청에 따라 별도 적용합니다.

## 적용과 검증

- 실제 저장 녹화로 새 상태 모델을 재생해 후크 최대60도, 롤러 최대120도, 최종0도를 확인했습니다. 실제 로봇을 실행하지 않았습니다.
- 설정은 `%USERPROFILE%/.seer_amr_console/do7_angle_profile.json`입니다. 지도/호스트/장착/CAD 기준이 맞는 경우에만 적용하며 다른 기준이면 기본 60/100도 구간을 사용합니다.
- 프로그램 완전 종료 후 재시작하면 적용됩니다. Viewer 재시작은 필요 없고 공식 SDK 직접 DO7 수신을 유지합니다.
- 새 시나리오로 변경했다면 정상 전체 녹화 후 **설비 배치 → 마커 자동 배치 설정 → 최근 전체 녹화로 DO7 열림 각도 기준 다시 맞추기**를 사용합니다.
- 이미 맞춘 후크 파지 기준 설비 배치를 유지합니다. ON 도중 설비를 후크에 따라 이동시키지 않습니다.
- 이 표시 모델은 IO 구간 기반 애니메이션이며 실제 접촉·마찰·무충돌을 입증하지 않습니다. 설비 위치 탐색에서는 초기 파지점 3cm 이내 조건을 별도로 적용해, 신호로 문이 열렸다는 사실만으로 어느 설비 위치든 성공으로 저장하지 않게 했습니다.


## 힌지 축 보정

실제 SIMPLE_WHOLE CAD의 원래 왼쪽 회전축은 (-0.325911,-0.854152)m이고, 후크 파지점 중심을 맞춘 뒤 SDK 티칭 marker_to_left_hinge를 역변환한 축은 (-0.325732,-0.875171)m였습니다. 깊이 방향 차이가 약 21mm입니다. 이전 축은 CAD 전체 깊이의 중간값으로 추정한 값입니다.

후크 우선 배치 모드에서 왼쪽 축만 실제 티칭 상대 위치로 보정합니다. 손잡이 중심에서 축까지의 상대 벡터는 약 (-299.824,-36.769)mm입니다. 설비 전체 원점이나 실제 로봇 좌표는 변경하지 않습니다. 원래 축에서 5cm 초과 차이가 나면 모델 검토를 요구하며 적용하지 않습니다. 문 렌더링과 공유 문 추종 정의가 같은 축을 사용하고 Isaac mirror에도 수정한 회전이 전달됩니다.


## 롤러 접근과 실제 밀기 분리 (추가 수정)

두 번째 ON은 자세 변경/MoveL 앞에서 켜집니다. 이 신호만으로 롤러 개방을 시작했던 경로를 변경했습니다. 두 번째 ON 뒤에는 문 각도를 그대로 유지하며, 모델상 롤러 중심이 문 표면의 반경+15mm 이내에 들어오고 앞 표본보다 표면으로 접근하는 순간에만 밀기 추종을 시작합니다. 시작 후 ON 동안에는 계속 고정 추종하여 작은 거리 오차로 빠지지 않습니다.

저장된 최근 전체 기록으로 확인한 밀기 시작은 t=24.797초이며, 이후 실제 회전은 약68.782도였습니다. 접근을 포함한 전체 ON의131.189도를 기준으로 삼지 않고, 이 밀기 시작 이후의 회전량을 60도 추가 개방에 대응시켰습니다. 같은 기록을 재생하면 접근 중60도 유지 → t24.797초 이후 개방 → 최대120도 → 마지막0도입니다. 이번에 막 실행한 세션의 전체 자세는 별도 저장되지 않아 이 검증은 기존 저장 기록에 대한 재현입니다.

앞으로 Real 3D의 DO7 표시 입력과 상태는 do7_cycles/latest.json에 자동 기록합니다. Runtime에서 시나리오를 실행한 경우도 화면이 켜져 있으면 기록됩니다. 접근/밀기 시작/신호 전환 시각과 표시 각도를 확인할 수 있으며, 이는 전체 6축 자세 녹화와 별도의 경량 진단 기록입니다.
